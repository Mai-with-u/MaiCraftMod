## 1 范围

v0 有五个入口做载具：`physical_assembly`、`physical_balance`、`physical_control`、`fly_vehicle`、`operate_machine.drive_vehicle`。v1 的分法（第 10 节第 1 项）：**载具也是机器**，看、审、设置都用机器能力；只有机器能力里没有的两件事——把方块变成会动的结构、坐上去开——各给一个能力。

| v1 能力 | 一句话 | 取代的 v0 能力与操作 |
| --- | --- | --- |
| `vehicle_assemble` | 把建好的方块组装成会动的结构（物理组装器，或车站组车），或者拆回方块 | `physical_assembly` 的 assemble / disassemble；列车组车（v0 没有） |
| `vehicle_drive` | 坐在驾驶座上开：试按控制件看反应，或开到一个地方停稳 | `fly_vehicle` 的 fly、`operate_machine.drive_vehicle`、`physical_control` 的 press_typewriter_keys 与 turn_crank |

## 2 真人怎么做

**造飞艇**：先在地上把船体搭好：座位、无线红石打字机、热空气燃烧室和气球蒙皮（浮力）、螺旋桨轴承加桨叶（推力）、扭力弹簧加定向齿轮换向器接风帆（转向）。用强力胶或蜂蜜胶把整艘船框起来，旁边放物理组装器，按住右键拉杆，方块就变成一条会动的船。造好先看重心歪不歪：开着桨和关着桨都不能一头栽；歪了就在轻的那头加铁块，起飞前调好，不在天上加。

**造车**：车轮悬架装轮子，舵轮或打字机接模拟传动器控制转向和动力，同样胶起来组装。

**组火车**：铺轨，放车站，车站切到组车模式，在轨道上放转向架、列车操纵台、外壳，用强力胶粘好，按车站界面的组车按钮。写一张时刻表（去哪站、等多久），交给坐在操纵台上的列车长（村民、烈焰人这类），车就自己按表跑。

**开**：坐上驾驶座，接管打字机（或拿着遥控器、或坐到列车操纵台），先轻按一下看看这个键让船往哪动，再正式开：飞艇先垂直升起来，到高度再往前，到目的地上空减速、垂直落下，停稳了松开所有键再下来。车就是踩油门、打方向、到了松油门刹住。

**装置控制**：装置控制器装在会动的装置上，拿个过滤物品放进去，就能在装置动着的时候开关某类工作头（比如只停钻头）。无线红石链路左右两个格子放两样东西就是频率。遥控器（Create 的无线遥控器）绑好六个按键的频率，拿在手里右键启用后，按方向键、跳跃、潜行就发信号；放在讲台上站在讲台前用也一样。

## 3 新逻辑

### 3.1 载具是一台机器，档案跟着结构走

```text
载具      一台机器（机器规格 3.1）：机器方块 + 网络 + 档案；另外多一样"它是一个会动的结构"
          结构的种类：Sable 物理结构（观察编号 s#）、Create 列车（列车编号，车厢 e#）、Create 装置（e#）
档案      MachineArchive 照旧，加：结构身份（Sable 子世界编号 / 列车编号）、坐标系（世界 / 结构局部）、
          驾驶座位置、操纵表（3.5）
组装前    蓝图与档案用世界坐标（锚点 + offset）
组装后    同一份档案改用结构局部坐标（origin_storage 起算，VA-08）；整机比对按结构局部坐标读
重新组装  拆回再组装会得到新的结构编号：vehicle_assemble 自己把档案迁到新编号（VF-18 v0 不迁移，飞控档案就丢了）
```

档案跟着结构走的做法：

- 按结构身份存着的只有操纵表（试过的、LLM 定的行和车头）；控制回路每次现读，受力每次现问服务端，所以跟过去的是操纵表，拆前的回路与方块清单只拿来比哪里改过。
- 拆回：把操纵表连同拆前的控制回路（每个输入的频率与收端旁的执行件）、方块清单（方块 ID → 格数）改记到世界里组装器落回的那一格，按维度与坐标存；车头从结构自己的轴换成世界朝向——拆回时结构先摆正到最近的整 90° 再落下，再组装出来的结构自己的轴就是组装那一刻的世界轴。按旧结构身份存的那份删掉。拆回后找不到组装器落在哪，档案留在原身份下照实说。
- 再组装：从同一台组装器（同一格）组装出新结构时拿方块清单认：两边共有的格数占多的那边一半以上就认作同一艘——拆回本来就是为了改船，不要求一模一样。认出来就把操纵表搬到新结构身份上，结果写跟到了哪个 `s#`（新结构在观察里领编号要一两刻，组装后等它最多 10 刻），并照现场列出方块的增减和控制回路的变化（多了、没了、接线变了的输入）。接线变了的输入，试过的角色不带过去（原来的试按结果已经不算数，要重新试按），LLM 定的照带（以它为准）；输入没了的都不带。
- 认不出（共有的不到一半，或哪边的方块清单没读全）照新载具处理，结果说明为什么，旧记录删掉。这台组装器没有拆回记录也是新载具。车站组车、拆车没有物理组装器，不谈档案。

- 结构在动时，整机比对、设置、施工照样能读，但改方块（`machine_build`）要等停稳（VP-08）：真人不在飞行中加配重。等的时候按进度跟踪，200 刻（VA-07）不停就如实结束、写明还在动。
- 最后一块方块拆掉，Sable 会删掉整个结构（VP-09，事实）：档案标成已拆除。

机器档案（`machine_build` 建的那份）跟着结构走：

- 组装：组装器落在哪份机器档案里，那份档案跟到新结构。组装是纯平移（组装器收进的第一块方块落到地块中心，不转向，胶也跟着搬进地块，F），所以锚点平移到地块里、蓝图偏移一格不变。
- 拆回：记在这个结构上的机器档案跟回世界。拆回以组装器为轴转整 90°、落到组装器当时所在的世界格（F），锚点按组装器落点和转的那一下换算，蓝图（格、方块朝向、部件的面、安装段、设置）跟着转。找不到组装器落在哪，档案留在结构身份下照实说。
- 操纵表照上面按结构身份跟，两份档案在同一次组装、拆回里一起跟，不会一份在船上一份在地上。

**停稳的结构上施工**（`machine_build` 指 `s#`，或指已经跟到结构上的档案名）：

```text
局部坐标 原点：结构上有跟过来的机器档案时是档案锚点（造的时候蓝图的偏移照用，s# 和档案名两种写法同一套坐标）；
         没有档案时是结构上的物理组装器。x、z 是组装那一刻的世界东西、南北（组装不转向），y 向上。
         两样都没有（不是物理组装器组出来的、组装器被拆了）时是 Sable 的地块中心（组装时收进的第一块方块）。
         machine_inspect(s#) 的 local 一节写明原点是哪一格、范围、座位和配重建议在局部坐标的哪一格
档案     指 s#：结构上已有跟过来的档案 → 补丁并进那份；没有 → 按 name 新建一份记在这个结构上，锚点是物理组装器
         （没有组装器时是地块中心；name 不给按结构名，没名字叫"载具@s#"）
等停稳   开工前在动：等它连着 10 刻不动再开工，等的时候按进度跟踪；200 刻（VA-07）还在动就如实结束、写明还在动，一格没动（C）
够到     每一格先看此刻站着够不够得着、看不看得见；不然挑站位：甲板上能站的格（人在船上就在船上走，不在就先上船）
         或船边地上站得住、身体不压着要放的那一格的格；挖方块先挑船上（站在地上挖船上的方块，Sable 会把船推一下，F），
         船上够不着才在地上挖；都够不着记"够不着"，不擅自拆船，也不往船上垫临时方块（会改船的重量和样子，C）；
         人坐在船上的座位上（开完船还没下来）：坐着够得着就坐着做，够不着先按潜行下座位再挪
放、挖   施工引擎照常：备料、清障、砌筑、开关门、复查；放置预测按结构自己的轴算朝向（Sable 放方块时把人的朝向换到结构里，F）；
         扳手转向是普通右键、不潜行（潜行右键会拆），只点能转到设计方向的面（VP-10）；结构上倒桶还不会，照实记
安装段   胶（强力胶、蜂蜜胶）在结构上补：拿胶、站到够得着的地方、发一包带地块坐标（服务器按结构位姿核距离，F）；
         别的安装段、部件、装后设置在结构上还不会，逐条照实写"结构上还不会"，不去点
动起来   施工途中结构连着 10 刻在动（被撞、被风吹、从地上挖推的）：停手结束，写明动了、做到哪；不追着动着的船施工（C）
结构没了 最后一块方块拆掉、结构不见了：已确认的拆放照算，档案标成已拆除
比对     结束按结构局部坐标整机比对：changes、每格结局、没对上的格；坐标都是局部坐标，不给地块里的大数
```

- 指世界里的档案名、坐标、地点照旧在世界里施工；指跟到结构上的档案名时 `machine_inspect` 也按结构读：给 `vehicle` 一节，再按结构局部坐标和档案整机比对。
- 加完配重再看受力：受力每次现问服务端，`machine_inspect(s#, balance=forces)` 读的就是加完之后的结构；施工完把这个结构的逐格读结果作废，观察和 `vehicle` 一节也照新结构读。

### 3.2 读：`machine_inspect` 的载具部分（只读）

载具类型的机器（由 `compat.sable`、`compat.create` 登记的 `MachineType`）在 `machine_inspect` 的结果里多出 `vehicle` 一节：

| 字段 | 内容 | 依据 |
| --- | --- | --- |
| `kind` | `airship` / `plane` / `car` / `boat` / `train` / `contraption`，判不出 `unknown`；没有驾驶座或控制件的物理结构是 `structure`（不是载具，09-11 用户原话）。物理结构按这个先后认：有浮力（燃烧室、蒸汽喷口、气球、浮空水晶）是飞艇；没有浮力、有机翼（3.7 固定翼一段）又有推进是固定翼，带车轮也是；有车轮是车；浮在水上是船；只有推进的说不清 | VD-03 |
| `seats` | 座位位置，哪个是驾驶座（座上够得着控制件的那个） | VD-05 |
| `controls` | 控制回路：每个输入（打字机某键、舵轮、油门拉杆、拉杆、遥控器某键）→ 频率 → 接收器 → 执行件（螺旋桨轴承、模拟传动器、定向齿轮换向器、车轮悬架、燃烧室……）；外部同频发射端（别人可能在远处遥控） | VD-01、VD-02、VD-04 |
| `control_map` | 操纵表（3.5）：哪个输入是动力、刹车、俯仰、横滚、偏航、升力、转向；推出来的、试过的、LLM 改过的分开标 | VF-01 |
| `balance` | 受力（3.3）：质量、重心、浮力中心、推力；开着动力与关着动力两种情况下的倾覆力矩与倾向；给 `balance=ballast` 时附配重建议 | VP 组 |
| `state` | 动没动、速度、姿态（俯仰、横滚）、接地（服务端给 GROUNDED / AIRBORNE / UNKNOWN，VF-14）、谁坐在驾驶座 | VF-14 |
| `local` | 结构局部坐标（3.1）：`origin` 原点是哪一格（档案锚点 / 物理组装器 / 地块中心）、`archive` 跟到这上面的机器档案名、`min` / `max` 方块范围、`seats` 座位所在的格、`ballast` 配重建议所在的格，都按局部坐标；在船上施工照这一套写偏移 | 新 |
| `stabilizers` | 装着 Create: Flight Control 的稳定器时才有（3.11）：每个高度稳定器、智能姿态稳定器、线速度耦合器开没开、有没有动力、怎么出力、模式、目标与当前高度、最大目标速度；飞控红石代理每个接了动作的面接到哪个打字机键、转给谁的哪个动作；`driven_by` 写 `vehicle_drive` 开它走"设目标高度 + 给方向"（`stabilizers`）还是照旧按键（`keys`）及原因 | 新 |

回路读不全（结构太大、部分没加载）→ `kind=unknown`、`controls.complete=false`，不猜（VD-03）。

### 3.3 受力：静态两种情况，加配重建议

v0 有一套离线刚体时域仿真（启动、停止的延迟，四向扰动，迎流，施工中间状态，VP-03、VP-04）。v1 只算**静态的两种情况**（第 10 节第 2 项）：

```text
读       服务端只读操作 sable.body：质量、重心、惯性、当前速度与接地（VP-01；客户端读不到质量）
         客户端读结构的方块：浮力源（气球蒙皮围的气体体积 × 燃烧室供气、浮空水晶）、
         推力源（螺旋桨的位置、朝向、按当前或给定转速的推力）、车轮与支撑（VP-11～VP-13）
算       关着动力：重力 + 浮力 → 绕重心的力矩，往哪边倒、倒多快（以角加速度表示）
         开着动力：再加上各推力 → 同上
         两种情况都"不倒"才说平衡；这是用户 10-02 要的"开起来还是停下来都能保持平衡"
配重     balance=ballast：在结构里找能放方块的空位，按"放一块铁块（或给定方块）能把两种情况的力矩都压小"
         排序，给前几个位置与放了以后的预测；不自动施工（VP-07），LLM 用 machine_build 加
说明     预测不是实飞：结果固定带"实飞要靠 vehicle_drive 验"（VP-14）；算不全（模组没给浮力数据）写明哪部分没算
```

受力只在组装成结构以后看：质量与重心要服务端读 Sable 的真实数值，蓝图阶段读不到，按方块"轻""重"几档估出来的数和实际对不上，反而把 LLM 带偏。起飞前的检查这样做：在地上组装好，`machine_inspect(s#, balance=forces)` 看两种情况；不平就 `balance=ballast` 看配重放哪，直接在停稳的船上用 `machine_build` 补（3.1），再看一次，然后才起飞。`machine_review` 对载具蓝图只审建不建得出、缺什么料，不给 `balance`。

### 3.4 组装：`vehicle_assemble`

```text
0 已满足     assemble：目标方块已经是一个结构 → 完成"已经组装过"；disassemble：已经是方块 → 完成
1 找         目标是档案名或观察编号；物理结构要看到物理组装器，列车要看到车站与轨道上的方块
2 胶         物理结构：档案的范围有没有被同一种胶完整覆盖（VA-02）；没覆盖 → 交机器的安装段先粘
             （胶选区是里程碑三机器会话做的安装段；斜对角相接的方块也会被带上，VA-10）
             档案：组装器那一格落在哪份机器档案里，取它声明要放方块、此刻真有方块的格；不在任何档案里不补，直接拉
             盖全：每两块相邻的同在一块强力胶框里（现有的胶都算）；缺的由会粘胶的机器类型算框（MachineType.stickTogether）
             框里不夹档案外的实心方块（垫的、地面不跟着走，C）；补胶没补成就不拉杆，照实说粘了哪些、还差哪些（C）
             强力胶不把轴承转子（朝向那面那一格加连着的风帆类方块）和船身粘在一起，只粘轴承和转子头：
             机械动力的轴承转起来会顺着强力胶把船身拖进转子（F）
             身上有蜂蜜胶先用蜂蜜胶（只粘物理结构、框不讲究角，MachineType.stickPreference 定先后），没有用强力胶；
             蜂蜜胶补到一半没成不换强力胶，照上一条不拉杆（C）
3 等停稳     结构在动不碰（VA-07）
4 拉一次     物理结构：走到组装器旁，按住右键拉杆一次（原生做法，思索场景原话）；
             列车：车站切到组车模式、按组车按钮一次
             请求发出后只观察，不再拉第二次——再拉会拆回去（VA-04）
5 确认       真的转换了（出现新的结构 / 列车）才算；处理了但没转换 → 完成并写明"没有变成结构"（VA-05），不判失败
6 迁档案     档案跟着走（3.1）：拆回改记到组装器落回的那一格，组装认出是拆回的那一艘就跟到新结构；
             存档失败也保留已经发生的组装（VA-06）
```

- `operation=disassemble`：物理结构用任意一个物理组装器拆回（事实）；列车开回车站、车站切到拆车。拆回后档案改记到世界里组装器落回的那一格（3.1）。
- 别人的载具：点名即许可（M7）；自家人的也照归属看。
- 黏液球合并两个结构、断开部分会自动分离（VA-10）：事实写进能力说明，不另做操作。

### 3.6 操纵表：Mod 从回路推，试按确认，LLM 可改

v0 要 LLM 第一次飞之前交一整份飞控档案（VF-01），只校验 power（VF-02）。v1（第 10 节第 3 项）：

```text
推     从控制回路推每个输入的角色：
         接到螺旋桨轴承、桨朝后的 → 动力；接到燃烧室或浮力的 → 升力；
         接到转向机构（扭力弹簧 + 定向齿轮换向器 + 风帆，或车轮悬架的转向）的 → 偏航 / 转向，左右按接线方向；
         接到模拟传动器、车轮驱动的 → 动力 / 刹车
       推不出、或者一个输入接了几样 → 标"未定"
试     vehicle_drive(operation=test) 时（或第一次正式开之前，结构停在地上/水面上），每个已推出的输入轻按一下：
         回中性停稳 8 刻 → 按住一档 → 观察窗口覆盖原生延迟 → 看真实的位移、转角、升降（VD-08、VD-09）
         和推的方向对得上记"试过"，对不上按实测改并写明
         固定翼的舵（升降舵、方向舵、副翼）停在地上试不出：没有气流，舵面转了机身不动（F）。
         固定翼按舵键看不出动时不记成 none，留着推出来的那行，response 写"固定翼的舵要有速度才起作用，按接线定"；
         动力键照常试（桨停着也推得动），车头照常从动力键看出来
改     LLM 用 machine_configure 的 controls 设置直接写某个输入的角色，标"LLM 定的"，以它为准
```

正式开之前，开这一类载具必需的角色（飞艇：动力 + 升力 + 偏航；固定翼：动力 + 偏航或横滚（左右至少一个），俯仰、刹车没有也能开；车：动力 + 转向；船：动力 + 偏航）有缺 → `vehicle_drive` 以 `NOT_POSSIBLE` 结束并写明缺哪个角色——这是缺了就没法开的事实（没有升力的飞艇飞不起来、没有转向的固定翼对不准跑道），不是对设计好坏的预判。

### 3.7 驾驶：`vehicle_drive`

```text
0 校验     目标载具（档案名 / 观察编号）；operation=test（给 inputs）或 drive（给 target 或 direction）
1 上车     不在车上 → 出行方式规格 3.4 登上 → 坐到驾驶座（use）；坐上去确认是这辆的驾驶座（VB-14：人必须在船上）
2 接管     打字机：空手连接，等服务器确认本玩家持有控制（200 刻内不确认 → 结束，VF-03）；
           遥控器：拿在手里右键启用；讲台遥控器：站到讲台前使用；
           接管前先关掉别的界面（VD-12）；控制回路和上次看的不一样 → 先写明再开（VD-10）
3a test    按 inputs 逐条按住给定刻数，每 5 刻记录点名部件与结构的变化，然后松开（VC-07）；
           原生不逐键同步，按下去不等于收端通电（key_state_confirmed=false），看实际位移判断
3b drive   按载具种类跑控制器（下面）；每刻核对还坐在驾驶座、还持有控制、回路没变
4 停       到了：刹停 → 松开本次按下的所有键 → 断开打字机 / 停用遥控器 → 停稳确认（VF-13）
5 结算     动作成没成（输入发了没有、松开了没有）、开到了没有、停稳了没有，三件事分开写
```

**飞艇**（VF-04、VF-06、VF-07）：起飞前按实测质量与供气求悬停的升力前馈，求不出用默认值，不当准入条件；先垂直离地约 8 格、姿态稳了（俯仰横滚 < 8°、角速度 < 0.15）再往前、再转向；巡航高度不给就取 max(当前, 目的地) + 32；到落点上方水平 ≤ 1 格、水平速度 < 0.3 再垂直下降，按实测漂移修正，近地停桨。

**地面车与船**（VD-07～VD-09）：开之前回中性；不建力学模型，按试过的响应开：逐档加油门，测到同向推进就保留低档，不为校准猛踩；低速转向按曲率识别；朝下一个航点转向，到了松油门刹住。车走的是地面，路线用寻路（车身宽度当身体宽度）；船只在水面上走直线加局部避让。

**固定翼**（`kind=plane`，第 10 节第 4 项）：靠机翼飞，不能悬停，要从地上滑跑起飞、找一条够长够平的跑道降落。

```text
认       没有浮力、有机翼又有推进（螺旋桨这类）的物理结构。机翼是结构上固定、会产生升力的方块：机械动力的普通风帆、
         风帆框架（Sable 让它们在物理结构上产生升力：垂直于帆面，按它的速度，越快越大，越高越弱，F）；
         装在轴承正面跟着转的（螺旋桨桨叶、舵面）不算。对称风帆只产生阻力（F），是舵和稳定面，不算机翼。
         带车轮也是固定翼（车轮当起落架）；有燃烧室、蒸汽喷口、气球、浮空水晶的一律按飞艇开（能悬停，垂直起降最稳）；
         装了能用的飞行稳定器照稳定器的开法开（3.13），不滑跑
角色     必需：动力 + 偏航或横滚（左右至少一个），车头照常要知道。有俯仰、刹车、倒车、地上的转向（前轮打方向）就用；
         没有俯仰键靠油门管高度（升力随速度涨，F），下面"抬头帮一把""微微抬头"两步跳过
滑跑     起飞跑道就是此刻机头前方的地面，开之前不拿跑道够不够长拦着，也不在地上掉头找方向：满动力往前，
         偏航（地上有前轮转向也用）修方向、有横滚把机翼摆平，俯仰不动。每 5 刻量一次前方：沿机头、宽是翼展再加 2 格的一条，
         地面连着（不断、不是液体，浮在水上起飞的前方水面也算）、高低差 ≤ 1 格、机身那么高里没有挡的方块、都加载着，
         畅通到哪就是跑道到哪
  离地     接地变离地连着 3 个样本、船底比起飞时高 1.5 格以上 → 爬升；这一刻的水平速度记成实测离地速度，滑了几格一起记下
  帮一把   速度连着 1 秒不再涨、还没离地：有抬头键就抬到约 10° 帮它离地
  中止     剩下的畅通地面不够此刻速度刹停（每秒几格 × 2 秒，再加机身半长），或满动力 30 秒还没离地、速度也不涨了：
           收动力、按刹车（有），刹停，照实写滑了几格、最快每秒几格、为什么停（C：跑道尽头前没离地就收油刹车）
爬升     离地 8 格以内沿跑道方向直着爬，不转弯、不压坡度（翼尖会擦地）；之后转向目的地，爬到巡航高度。
         速度跌到实测离地速度的 1.1 倍以下：先保速度（压机头或不再抬头，没有俯仰键就不加爬升）；
         满动力连着 5 秒每秒升不到 0.3 格还没到巡航高度：就按此刻的高度巡航（越高升力越弱，F），写明巡航高度降到多少
巡航     巡航高度同飞艇：不给取 max(当前, 目的地) + 32，沿途往前看 max(48, 速度 × 5) 格，地形高了就抬；
         转弯：有横滚就压坡度（不超过 30°）配上偏航，只有偏航就平着转；高度：有俯仰按高度差调俯仰角，没有就靠油门
找跑道   离目的地 128 格内开始找落地的跑道（只看已加载的，没加载的不当畅通），这期间在目的地上空绕圈飞，不悬停：
           候选   目的地 ±32 格每 8 格一个，每个试八个朝向，先近后远、和飞来的方向顺的先试
           一条   一长条地面：宽 = 翼展 + 4；长 = 这一趟实测滑跑距离 × 2 + 机身长，至少 48 格（空中接手、没实测按 96）；
                  地面连着、不是液体、高低差 ≤ 1 格，机身高度再加 4 格以内没有方块；
                  跑道头往外 120 格的下滑线下面至少空 3 格（树、山挡着不行）
           找不到 目的地附近没有 → 放宽到 ±96 格；还没有 → 飞回起飞时的跑道（刚从那离的地，够长）
进近     先降到跑道上方 12 格，飞到跑道延长线上离跑道头 120 格的进近点，到了转向对准跑道：
         朝向差 < 15°、离中线不超过半个翼展才开始下滑；没对准就绕回进近点再来（算一次复飞）
下滑     沿约 6° 的下滑线降（前进 10 格降 1 格）：速度保持在实测离地速度的 1.2～1.3 倍，油门管速度、俯仰管高度
         （没有俯仰键油门管高度）；偏航、横滚对着中线修
拉平     离跑道 2 格高或每秒几格 × 0.15 格高（取大的）：收动力，有抬头键微微抬头 → 接地
接地     接地连着 3 个样本 → 收动力、按刹车（有）、偏航和前轮转向保持方向，慢到每秒 0.35 格以下松开所有键 → 停稳确认；
         接地后又弹起来不加动力，等它再落；冲出跑道照样刹，写明冲出了几格
复飞     下滑中离中线超过一个翼展、朝向差 > 30°、过了跑道一半还离地 1 格以上、速度跌到实测离地速度的 1.1 倍以下、
         跑道上出现了挡路的方块，或拉平后 5 秒还没接地（C）：满动力、抬头爬回进近高度以上，绕回进近点重来。
         同一条跑道连着 3 次落不下换下一条候选；候选都试过回起飞跑道；起飞跑道也连着 3 次落不下，
         第 4 次照最后那样硬落下去、不再复飞，落地后照实写偏了多少、停没停稳
到了     停在为目的地挑的那条跑道上就算开到了（arrived）；离目的地还有多远照实写进 distance_left，
         travel(via=vehicle) 下车后走完最后一段
```

- **舵的方向飞着核对**：滑跑和飞行中第一次用某个舵键（俯仰、横滚、偏航）时看机身真实往哪转，连着 10 刻转反了，这一趟就把这一对键反着用，结果写明哪个键实际是什么。操纵表里推出来的、试过的那一行改成试过（飞着看出来的）；LLM 定的那一行不改，照实说，改不改由 LLM 定。
- **失速与翻转**（实时自保）：飞着速度跌到实测离地速度以下，或横滚超过 60°、俯仰超过 ±40°：先松转向、摆平机翼、压机头（有俯仰键）、满动力，恢复了再接着飞；离地 8 格以内翻了，松开所有键交给坠落自救。
- **动力没了**（平飞时满动力连着 3 秒还在掉速、保不住高度——燃料烧完、过载停转）：就近找跑道迫降（同下面"打断与意外"的固定翼那条），写明动力没了。
- 阶段写进 `drove.phases`：`takeoff_roll` 滑跑 / `stop_takeoff` 中止起飞 / `climb_out` 爬升 / `cruise` 巡航 / `approach` 进近 / `descent` 下滑 / `flare` 拉平 / `rollout` 落地滑跑 / `go_around` 复飞 / `landed` 停下；`landing` 写落在哪条跑道（跑道头、朝向、长）、怎么挑的。

**航迹与落点**（VF-10～VF-12）：约每 5 刻重查前方已加载的空域，机身和自己的转子一起算，没加载的不当畅通；不是全世界寻路。飞艇的落点在目的地 ±32 格每 8 格一个候选，场地要盖得下机身加余量、地表高差 ≤ 1、不是流体；固定翼的跑道按上面固定翼一段挑。

**按键**：打字机只有按下 / 松开，几个角色同时要按时按 4 刻一周期混合（VF-09）。

**停稳确认**（VF-13）：接地后刹停、松键断开，服务端确认释放，且接地、速度 < 0.35、倾角 < 8° 连续 20 个样本；100 刻内做不到就结束并写明"落地了但没停稳"——这是 v0 实机唯一一次飞艇试飞失败的地方，验收要专门看。

**打断与意外**：
- 暂停、取消、被打断（M6）：就近找落点降落停稳再交出（VF-15），不悬停在空中等；地面车就地刹停。
- 固定翼不能悬停，暂停、取消、不急的需求、受伤、时间用完都是就近找跑道降落停稳再交出：在此刻位置 ±128 格已加载的地里找，够长的先、近的先；没有够长的就挑最长的一片平地迫降（宽 = 翼展 + 2，其余同跑道），不回起飞跑道；滑跑中被叫停就中止起飞刹住。停稳后坐在驾驶位上等（同飞艇）。收尾照内核的规矩最多等两分钟：到点还在天上就照规矩松键交出，固定翼松了动力会往下滑，交给坠落自救，结果写明。
- 立刻要处理的事（会摔死这类）插进来：松开所有键交出；固定翼会往下滑，结果写明。
- 坐着掉落（结构翻了、被撞下来）：坠落自救接手前先松开驾驶的键（VB-13）。
- 控制回路被改、座位没了、结构不见了、控制被别人拿走：立刻松开本次的键并结束（VD-10、VF-03），写明是哪一样；不硬抢。
- 开着开着受伤：飞艇先降落再交给自卫，固定翼就近找跑道降落再交给自卫，车先刹停。

**沿途记录**（VF-16）：飞过、开过的地方照常被动记进世界记忆（群系、结构），和步行一样。

### 3.13 装了飞行稳定器的飞艇怎么开

Create: Flight Control 的高度稳定器保持一个目标高度（结构转动点的世界 y），智能姿态稳定器把船身配平，线速度耦合器按飞控红石代理收到的方向信号沿机体轴推、没信号就刹。能用它们时，`vehicle_drive` 开飞艇（`travel(via=vehicle)` 同样）改走"设目标高度 + 给方向"，比按键混合升力、动力、转向稳得多：

```text
能不能用   三样都要能干活：底下的轴在转、没过载，接了飞控计算机或开了直接施力（没地方出力就是算了也不出力，F）；
           无线红石打字机的键经代理接到耦合器沿机体 +x、-x、+z、-z 四个方向（船不转向，直接往目标滑，所以四个都要）。
           种类是车、船不用；推进器不在认得的名单里、种类说不清的也照飞行器开
           能用时不查升力、转向键和车头；用不上照旧查操纵表，缺角色开不了时连同稳定器为什么用不上一起说
开之前     坐上驾驶位后核对要改设置的稳定器在驾驶位 8 格内（服务器只认 8 格内的设置，F）；
           没开的姿态稳定器、耦合器打开，耦合器最大水平目标速度是 0 的设成每秒 6 格（不设就只会刹），读回核对
飞         飞控只给"船底该在多高"和"水平往哪走、多快"：
           起飞目标离地约 8 格，到了姿态稳了再走 → 巡航目标是巡航高度，离它还差 6 格以上先升不走 →
           进近按剩下的距离放慢 → 落点上方水平 1 格内、水平速度 < 0.3 才降，目标每次比此刻低一截
           （离地 12 格以上每秒约 4 格、以内约 1 格），近地不再修水平，目标压到地面下 0.3 格 → 接地交给停稳确认
设高度     船底高度加上转动点比船底高的那段，设进高度稳定器（保持设定高度、开着）；差够半格、隔够 10 刻才改，
           改了读回核对，60 刻没收下照实停（离得太远、被红石切了模式）
给方向     想要的水平速度换到机体轴上，按耦合器那根轴的最大速度折成 ±x、±z 四个键各按多少，超了两根轴一起缩，
           4 刻一组按比例按（和按键开同一套调法）；松开键耦合器就刹
```

- 坐着够不着稳定器、打开或设速度后读回不对：按键开飞艇要的角色（动力、升力、偏航）和车头都齐，就照旧按键开并写明为什么没用稳定器；不齐照实停在地上。
- 改的设置开完不改回：高度稳定器留在落点高度，打开的、设了速度的照样开着、设着，结果写明改了什么。真人要飞也是先把它们开好。
- 停稳确认、按要求先停、被打断、时间用完、前方地形抬高巡航高度都和按键开一样；被打断松开键时高度稳定器还保持着最后的目标，船悬着不往下沉；中途做不下去停下时，结果写明船悬在哪个高度。
- 角速度耦合器、距离耦合器、飞控计算机的分配不接；改它们用各自的界面。

## 4 能力说明

### `vehicle_assemble`

| 参数 | 必填 | 说明 |
| --- | :---: | --- |
| `target` | ✅ | 哪辆：载具档案名（`landmark` 写法）或观察编号（`seen`，物理结构 `s#`、组装器或车站 `b#`） |
| `operation` | | `assemble`（默认）/ `disassemble` |

> 把建好、胶好的方块组装成会动的结构：飞艇、车、船用物理组装器（拉一次杆），列车在车站按组车按钮。拆回就是反过来。拆回改完再从同一台组装器组装，档案自动跟到新结构上，改过的地方照实列出。胶没覆盖完会先补胶。拉过杆就不会再拉第二次（再拉会拆回去）；处理了但没变成结构也会照实说。

结果细节：`structure`（新结构编号与种类）、`glued`（拉杆前补胶：组装器所在的档案、补上的框、补胶没补成时还差的框、一句话）、`archive`（档案这次怎么走的：`state` 是 `moved_to_world` 改记在世界里 / `followed` 跟到新结构 / `new_vehicle` 当新载具 / `kept` 留在原身份下；`structure` 现在记在哪；`changes` 方块与回路的变化；`dropped` 没带过去的操纵表行；`note` 一句话）、`machine_archive`（机器档案这次怎么走的：`name` 档案名，`state` 是 `on_structure` 跟到结构上 / `in_world` 跟回世界 / `kept` 没跟成留在原处，`note` 一句话；组装器不在任何机器档案里、结构上没记机器档案时没有这一节）。

### `machine_build`（载具部分）

参数照机器规格；`target` 多两种写法：物理结构的观察编号 `s#`，或已经跟到结构上的档案名。蓝图偏移按结构局部坐标（3.1），和 `machine_inspect(s#)` 的 `local` 一节同一套。

> target 给物理结构 s#（或已经跟到结构上的档案名）就是在组装好的船上施工：先等船停稳，再上船或站到船边够得着的地方，按结构局部坐标放、挖、扳手转向、补胶，最后按局部坐标整机比对。加配重就是在补丁里写几格铁块，加完用 machine_inspect(s#, balance=forces) 看受力。船在动不施工（真人不在飞行中加配重），施工中船动了就停手照实说；够不着的格照实写，不拆船、不往船上垫临时方块；传送带、部件、装后设置在船上还不会。

结果细节在机器规格的那份上多两样：`structure`（施工的结构 `s#`）、`local_origin`（局部坐标的原点是哪一格，一句话）；结构上施工时 `anchor` 不给（地块坐标对 LLM 没有用），没对上的格按局部坐标写。

### `vehicle_drive`

| 参数 | 必填 | 说明 |
| --- | :---: | --- |
| `vehicle` | ✅ | 哪辆：档案名或观察编号 |
| `operation` | | `drive`（默认）/ `test` |
| `target` | drive 二选一 | 开到哪：`position`、`landmark`；落点在附近 ±32 格内找 |
| `direction` | drive 二选一 | 往哪个方向开多远（同 `target=direction` 的写法） |
| `cruise_altitude` | | 只对飞艇和固定翼：巡航高度（世界 y） |
| `inputs` | test 必填 | `[{control, ticks}]`：按哪个输入（`打字机:W`、`遥控器:上`、`油门`……，取自 `machine_inspect` 的 `controls`）、按住几刻 |

> 坐到驾驶座上开自己的飞艇、固定翼、车或船。test 是轻按几下看看每个键让它怎么动（固定翼的舵停在地上试不出来，照接线定）；drive 是开到一个地方：飞艇先垂直升起来再前进，到了上空减速垂直落下；固定翼从机头前方的地面滑跑起飞，到了找一条够长够平的跑道对准降落，前方地面不够、还没离地就刹住；车和船开到附近刹住。到了会松开所有键、确认停稳了才算完。只想去某处的话用 travel(via=vehicle)，它会帮你上车、下车、走完最后一段。开之前先用 machine_inspect 看看操纵表齐不齐；缺动力、升力或转向就开不了。

结果细节：`control_map`（这次用的操纵表及来源）、`samples`（test 时每 5 刻的位移、转角、升降）、`flight`（阶段变化、最大倾斜、实际行程；`driven_by` 写是用飞行稳定器开的还是按键开的）、`parked`（停稳没有、用了几个样本）、`released`（键松开没有）。固定翼另有 `drove.takeoff`（`distance` 滑了几格、`liftoff_speed` 离地那一刻每秒几格、`left_ground` 离没离地）和 `drove.go_arounds`（复飞了几次）。

## 6 行为变化清单

1. **能力收拢**：五个入口变成两个新能力（`vehicle_assemble`、`vehicle_drive`），看、审、设置并进机器能力；`physical_balance.apply` 去掉，加配重就是 `machine_build` 的补丁。
2. **受力**：不再做启停时域仿真与扰动，只算开着动力、关着动力两种静态情况的倾覆力矩，加配重建议。
3. **操纵表**：不要求 LLM 交整份飞控档案；Mod 从回路推、试按确认，LLM 可改；缺必需角色开不了时如实说缺哪个。
4. **档案跟着结构走**：重新组装后自动迁到新结构编号。
5. **固定翼**：会自动起降——从机头前方的地面滑跑起飞，按飞的时候实测的离地速度定进近与失速的速度，到了找一条够长够平的跑道对准、下滑、拉平、刹停，落不好复飞；不要 LLM 声明抬轮速度（v0 要声明，也没实机验证过），前方地面不够不拒绝起飞，滑到不够刹停才中止。有机翼和推进、没有浮力的认成固定翼（带车轮也是），只有推进的改说不清。
6. **新增**：列车组车、写时刻表、交给列车长；遥控器与讲台遥控器的按键；装置控制器。
7. **驾驶中被打断**：就近降落停稳再交出（v0 同）；受伤也是先降落（v0 是整趟停）。
8. **在船上施工**：组装后不用拆回，停稳就在船上按结构局部坐标建、改、拆、补胶（v0 同，入口从 `physical_balance.apply` 换成 `machine_build`）；机器档案跟着组装、拆回在结构与世界之间来回走。

## 9 验收

离线（替身读写端）：

1. 组装：已组装直接完成；胶没覆盖先交安装段；拉杆只发一次；没转换照实完成；拆回改记到组装器落回的格（车头换成世界朝向、旧身份删掉），找不到落点留在原身份下；从同一台组装器再组装认出同一艘，操纵表跟到新结构，方块与回路的变化照实列出，接线变了的试过的角色不带；方块对不上、没拆回过都照新载具。
2. 受力：两种情况的力矩与倒向；配重建议让两种情况都变小；算不全写明。
3. 操纵表：按回路推角色；试按结果对不上时按实测改；LLM 改过的不被覆盖；缺必需角色 `NOT_POSSIBLE`。
4. 驾驶：飞艇阶段（离地 → 稳 → 前进 → 上空 → 垂直下降 → 停稳）；停稳确认 20 样本 / 100 刻；暂停就近降落；回路变了立刻松键结束；test 每 5 刻记录。装了能用的飞行稳定器时请求带上它的开法、不查升力转向与车头，只接了三个方向照旧查操纵表并说为什么，没装照旧按键；稳定器开法升够才走、下降目标不低于落点下一点点、设下去的目标高度是转动点高度、读回是自己设的才算收下、60 刻不收下照实停、开之前打开与设速度读回、够不着说离多远。
5. 时刻表：写入条目读回一致；没有列车长 `NOT_POSSIBLE`。
6. 在船上施工：停稳才施工（在动先等，200 刻还在动一格不动、照实结束）；施工中连着 10 刻在动就停手照实说；按结构局部坐标比对（有档案按档案锚点，没有按组装器）；挖方块先挑船上的站位；够不着不垫临时方块；胶在结构上补，别的安装段、部件、设置照实写结构上还不会；结构没了档案标成已拆除。
7. 船上改键：s# 的 `key.*` 交给船上的打字机，几台时改离角色最近的那台，和操纵表的设置混写报参数错；坐着够不着不下座位、照实说；存完等同步再读回。
8. 机器档案跟着走：组装时组装器所在的档案平移到地块（偏移不变）；拆回按组装器落点与转的整 90° 换回世界，格、朝向、部件的面、安装段、设置一起转。
9. 固定翼：
   - 认种类：不在转子上的普通风帆、风帆框架算机翼，桨叶、轴承上的舵面、对称风帆不算；带车轮还是固定翼；有气球、燃烧室按飞艇；只有推进说不清。
   - 必需角色：动力 + 偏航或横滚，缺了 `NOT_POSSIBLE`；没有俯仰键也能开（靠油门管高度）。test 按舵键看不出动不记 `none`、留推出来的那行。
   - 滑跑：离地连着 3 个样本才爬升，记下实测离地速度与滑跑距离；速度不涨先抬头帮一把；前方剩下的不够刹停就中止、照实写滑了几格与最快多少；前方再短也先滑，不在开之前拒绝；30 秒不离地、速度不涨中止。
   - 飞：离地 8 格内不转弯不压坡度；巡航坡度不超过 30°；爬不上去按升得到的高度巡航并写明；失速、翻转先摆平保速度。
   - 找跑道：长度按实测滑跑距离 × 2 + 机身长（至少 48 格），八个朝向，下滑线下要净空，没加载不当畅通；目的地附近没有放宽到 ±96，再没有回起飞跑道。
   - 进近与落地：对准才下滑；复飞的六种情形各触发一次复飞；同一条跑道 3 次落不下换下一条，起飞跑道 3 次落不下第 4 次硬落；拉平、接地刹停、停稳确认；停在为目的地挑的跑道上算开到了。
   - 打断：被叫先停在此刻位置附近找跑道降落（没有够长的挑最长的平地），滑跑中被叫停中止刹住；两分钟到点还在天上照规矩松键并写明。
   - 舵接反：这一趟反着用并写明；推出来、试过的那行改成试过，LLM 定的那行不改。

实机（实测实例，先在占坑表占"实机"）：

1. LLM 自己设计一艘带转向的小飞艇（蓝图 → `machine_review` 审材料 → `machine_build` → `vehicle_assemble` → `machine_inspect(balance=forces)` 看受力，不平就照 `balance=ballast` 在船上补配重再看），`machine_inspect` 看操纵表，`vehicle_drive(test)` 试按，`vehicle_drive` 飞到 200 格外降落**并停稳**（v0 唯一失败的地方）。
2. 四轮车：组装后开到 50 格外刹停。
3. 列车：组车、写两站往返的时刻表、交给坐在操纵台上的村民，车按表跑起来；再用出行方式规格的火车验收坐一趟。
4. 遥控器开一扇装置门：绑定、按住"上"一秒、门动了、松开。
5. 飞行中下 `goal(pause)`：飞艇就近降落停稳再停下。
6. 拆回改船再组装：试按过、定好车头的飞艇调个头停下后拆回，加两块铁块配重、把一个键改绑到别的频率，从同一台组装器再组装——结果写档案跟到新结构 `s#`，列出多了铁块、那个键接线变了；`machine_inspect` 看操纵表：没改的键试过的角色还在、车头跟着调过头的朝向换好了，改过的那个键要重新试按。
7. 装了 Create: Flight Control 的飞艇：高度稳定器、智能姿态稳定器、线速度耦合器都接动力，无线红石打字机四个键经飞控红石代理接到耦合器 ±x、±z——`machine_inspect` 的 `stabilizers` 写 `driven_by=stabilizers`；`vehicle_drive` 飞到 150 格外降落并停稳，结果 `driven_by=stabilizers`、写明打开了哪些、设了什么速度；把耦合器一个方向的键解绑再看，`driven_by=keys` 并说缺哪个方向。
8. 组装后在船上加配重：飞艇停在地上，`machine_inspect(s#, balance=ballast)` 看受力和配重建议的局部坐标，`machine_build(target=s#)` 在建议的位置加两块铁块（角色上船或站在船边放），结果按局部坐标比对全对；再 `machine_inspect(s#, balance=forces)` 看受力变了。施工中让别的玩家推一下船，看到停手并写明动了。拆回再看机器档案跟回世界、两块铁块在蓝图里转对了方向。
9. 组装后在船上改键：开完船停在地上、还坐在驾驶座上，`machine_configure(target=s#, settings={"key.Q": "物品甲 + 物品乙"})` 给打字机多绑一个键——坐着改好、原来的键都还在，`machine_inspect(s#)` 的 `controls` 里多出 `打字机:Q`。
10. 固定翼起降：LLM 自己设计一架小固定翼——机身两侧普通风帆当机翼、机头螺旋桨、机尾对称风帆做升降舵和方向舵（定向齿轮换向器 → 扭力弹簧 → 动力轴承）、车轮当起落架——组装后 `machine_inspect` 写 `kind=plane`，按接线用 `machine_configure` 定舵的角色。停在一条 150 格以上平直地面的一头、机头顺着它，`vehicle_drive` 飞到 400 格外：`phases` 依次有 `takeoff_roll` → `climb_out` → `cruise` → `approach` → `descent` → `flare` → `rollout` → `landed`，`takeoff` 写滑了几格、离地速度，落在挑的跑道上**并停稳**（`parked=true`）。
11. 跑道太短：机头前方 20 格就是墙，`vehicle_drive` 照样开始滑，在墙前刹住，结果写滑了几格、最快多少、没离地；开之前不拒绝，也不撞墙。
12. 飞行中下 `goal(pause)`：就近找跑道降落停稳再停下；把附近都换成树林（没有够长的地）再试一次，挑最长的一片平地迫降并照实写。
13. 目的地在密林里（附近没有够长够平的地）：放宽找，还没有就飞回起飞跑道降落，结果写明为什么回来。
14. 舵接反：故意把升降舵的两个键定反，起飞后结果写明哪个键实际是什么、这一趟反着用了，`machine_inspect` 的操纵表里 LLM 定的那两行没被改。
15. `travel(via=vehicle, vehicle=s#)` 开固定翼去 400 格外的一个地点：落地停稳、下来、走完最后一段。

| 6 | 其余附属模组（推进工程、深海潜艇、CC: Sable、工具枪、传动连杆、铁道模拟） | 只当方块（能认名字、能建能拆），回路里当未知执行件；要用再单独提 |

| 中止起飞 | 阶段 `stop_takeoff` | 滑跑时前方剩下的地面不够刹停还没离地，收动力刹住 | 09 第 3.7 节（开到某处那一行） |

v0 叫法进 09 第 2 节：`physical_assembly` → `vehicle_assemble`；`fly_vehicle` / `drive_vehicle` → `vehicle_drive`；`physical_balance` → `machine_inspect` 的 `balance`；`physical_control` → `machine_configure` 的载具设置与 `vehicle_drive(test)`；"飞控档案"→"操纵表"；固定翼的 `takeoff_speed`（LLM 声明的抬轮速度）→ `liftoff_speed`（飞的时候量出来的离地速度）、`fixed_wing` → `plane`、`bank_left` / `bank_right` → `roll_left` / `roll_right`。MCP 能看到的名字实现时同步 07 与更新日志。
