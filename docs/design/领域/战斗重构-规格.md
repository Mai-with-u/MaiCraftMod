## 1 为什么重构：审查发现

v1 的战斗在规格上不差，实现把 v0 打磨过的几处模型换成了常数，又把同一套打法写了两遍。逐条（位置都是 v1 `origin/v1`）：

## 2 真人怎么打

**看够不够得着**：剑能砍到的是"眼睛到对方身体表面三格"，大的怪离得远一点也砍得到，小的要凑近。怪打我也一样：它的手比自己身子宽出一截，斜着站更容易挨着。所以站位看双方的身板，不是看一个固定距离。

**一刀一退**：冷却好了上前砍一刀，没好就退到它够不着的地方等，盾在副手就举着；不站在怪手里干等。被打退了再上。

**看是什么怪**：
- 僵尸、蜘蛛：正面砍。
- 骷髅：要么冲上去近身，要么拿弓对射，绕到它射不到的地方再接近；不站在空地上跟它耗。
- 苦力怕：打一下退开，点着了就跑远等它熄。
- 一群：退到窄处、背靠墙，一次只面对一两只；先打最急的，不来回换目标。

**武器**：用手里最好的那把；对手举盾换斧；有弓有箭的远处先射；拿不出武器又被追，就跑。

**跑**：血见底、打不过就跑，往没怪的方向跑，不往怪堆里钻；甩开了才停。真跑不掉就背水一战。

**被人打**：被别的玩家打，先拉开、举盾，搞清楚是谁、为什么，再决定还不还手；自己点名要打的人，对方还手就接着打，打完收手。

## 3 新逻辑

### 3.1 一个战斗引擎，两处用

```text
Battle（behavior.combat，新包）
  每刻：战场快照 Battlefield → 决策 Tactic → 执行（脚 + 手 两层并行）
  点名战斗 fight（ability.fight）    = Battle(名单: 点名的编号 / 开打那一刻 radius 内看得见的敌对)
  自卫临时任务（behavior.survival） = Battle(名单: 正在威胁我的，无差别)，外面包一层"插曲"：
                                      记打点、开始与结束事件、打完回打点、回不去暂停主任务
```

- 出手、走位、追击、撤离、拾荒、卡住判断只有 `Battle` 一份；`FightTask` 只剩目标解析、许可、结果结算，`SelfDefenseTask` 只剩插曲记账（v0 `MobDefenseChain` 的做法）。
- 战斗相关的类从 `behavior.survival` 挪到新包 `behavior.combat`；生存需求（饥饿、夜晚、坠落……）留在 `behavior.survival`，自卫需求调用 `behavior.combat`。

### 3.2 几何：够不够得着、挨不挨得着（`CombatGeometry`，纯函数，全仓一份）

| 量 | 算法 | 依据 |
| --- | --- | --- |
| 我够得着它 | 眼睛到对方碰撞箱最近点的距离 ≤ 玩家实体交互距离属性（默认 3.0，药水、模组改了跟着变） | 原版 `Player` 攻击射线；比 v0 的"中心距 ≤ 属性 + 半身宽"更准（高低差、矮怪都对） |
| 它够得着我（怪） | 双方碰撞箱水平间隙每轴都小于 0.83（原版 `Mob` 攻击框的外扩），且高度上有重叠；"任何方位都够不着"的中心距 = (它半宽 + 0.83 + 我半宽) × √2 | v0 `Menace.strikeRangeOf` 的推导 |
| 它够得着我（玩家） | 对方的实体交互距离属性 + 我半身宽 | v0 同 |
| 苦力怕 | 引信点火 3 格、熄火 7 格；爆炸波及按威力两倍；充能的翻倍 | v0 `Menace` |
| 远程怪的射界 | 骷髅类 15 格、有视线；女巫、烈焰人、守卫者各按原版攻击距离 | 原版各自的攻击目标 |

### 3.3 战场快照与威胁分类（`Battlefield`）

- **我方**：真实血量与吸收、按护甲与韧性折算的有效血量、交互距离、手里与身上最好的近战与远程、盾、食物、退路（撤离连续失败）。
- **每只对手**：编号、身板、距离（中心与碰撞箱两种）、种类、是否正在追我、能不能走到（上一段寻路有没有路）、能不能看见、是否许可打它、引信状态。
- **种类按实体类认**（不靠 ID 名单）：近战（僵尸、蜘蛛……）、远程（`RangedAttackMob`：骷髅、女巫、烈焰人……）、爆炸（苦力怕）、飞行（恶魂、幻翼，按实体类而不是"无重力"标记）、会分裂（史莱姆、岩浆怪）、玩家。
- **正在追我**：十秒内真打过我的（伤害包认来源，箭消失了也认射手）、引信点着的、看得见又亮着原版攻击标记的、近处看得见的苦力怕、对战中的对手。只在附近游荡、隔墙的不算。
- **开打后还在追我**：这一仗里追过我的那只，攻击标记暗了也照样算追兵，只要还朝我来（往我这边挪、贴到快够得着我）；离开、站着不动或看不见满 3 秒才放下，死了、走出视野当场放下；在视野半径外 4 格内的照样看着。原版僵尸找不到路时攻击标记一秒一闪，不这样就"逼近↔打完了"来回切。

### 3.4 决策（`Tactic`，纯函数，参照 v0 `AttackPlan`）

```text
1 躲爆炸      有点着引信、在撤离范围内的会炸物 → 躲（压过一切）
2 已在撤离    撤离一旦开始就保持到甩开（退无可退除外），回了一点血不回头
3 打不过      面对威胁且有效血量或真实血量（含吸收）低于拒战线（4 颗心）→ 撤
              手上没有任何武器、又有会还手的在追 → 撤
4 挑目标      上次的目标还能打就接着打；否则先最急的（近处苦力怕），再最近的；同距按编号定
5 打法        有远程且（目标点着引信 / 走不到 / 手上没有近战武器 / 远程怪在射界外的高处）→ 远程
              否则 → 近战走位
6 挑不出目标但还有东西在追 → 继续走位（离开所有危险半径），不跑 32 格；引信熄了、怪凑上来下一刻自有目标
7 都没有      → 完成
```

威胁评估（能赢 / 有风险 / 打不过）只决定怎么打、要不要先退开拉距离，以及夜里露天要不要去备床，不决定开不开打：LLM 叫打的仗看着打不过也照打，差在哪（血、武器、同时面对的数量）写进结果的 attempts 当一句提醒，开打后血线破了照 3 撤。输入换成 3.3 的真实量：武器按实际每秒伤害、远程怪按射界与数量计。

### 3.5 执行：脚和手两层，互不排斥

**脚（走位）**：每刻给寻路一个目标——"离目标落在这个距离带里，同时尽量不进任何怪的危险半径"（距离带见下，危险半径按 3.2，进了就加代价而不是禁止，背水一战时也走得动）。近处（几格内、看得见、同一层）不走寻路，直接按带子前进、后退、站住（第十九轮的走位环，带子换成 3.2 算出来的）；远处、隔墙、高低差大的交给寻路。

| 打法 | 距离带 |
| --- | --- |
| 近战，冷却好了 | 内沿 = 它够得着我的距离；外沿 = 我够得着它的距离 − 0.15 |
| 近战，冷却中 | 退到它够不着我外 0.35～1.2 格，盾举着 |
| 远程 | 内沿 6～10 格（对手冲过来越快留得越多），外沿 = 内沿 + 4 |
| 玩家对战 | 冷却好了只短暂进入互相够得着的距离出手，没好就退到对方够不着外；远近切换 7 格换弓、4.5 格换回（防来回抖） |

近身的站位到了却还够不着（被方块边角卡住、怪在半格高的台阶上）：沿碰撞核过的短段补齐站位，补不齐的那一格交回寻路绕开，不原地空转（v0 `MeleeStanceRecovery`）。只在已经站到带子跟前时才数补站位的时间，还在走过去的路上不数。

**手（换武器）**：还在走过去、离对手四格外时先把最好的剑斧拿到手上：在快捷栏就按数字键；在主背包就开背包换进快捷栏的空格（没有空格换进放零碎东西的格，工具、吃的、水桶、火把不挪走），关上再按数字键选中——手里的镐留在原格，下回打架按数字键就切过去。换武器一旦开始就做完，"打完了"、贴到跟前都不中途收掉，换的那几刻不挥、不射；这一仗真结束（任务收尾）才收尾。贴脸了不为换武器开背包，拿快捷栏里最好的打。

#### 3.5.1 控距

现在的毛病：只盯着眼前这一只、只会背对它直线退一格，身后被方块挡住就站着挨打；目标在 5 格外、隔一层或看不见就直接交给寻路追，别的怪走到身后也不管。v0 是把"离目标在带子里、同时不进任何一只的危险半径"整个交给寻路，会侧移、会绕、会后退着上台阶。v1 这样做：

- **所有正在追我的怪都参与控距**，不只是打的那一只：打的那只按 3.5 表的带子，别的每一只都要求离开它的危险半径（3.2"它够得着我"再加 0.35 格）。
- **近处直接走位**（几格内、看得见，不经寻路，每刻都能变）：在八个水平方向（前后左右与四个斜向）里挑这一刻往哪迈——落点离目标落在带子里、离别的怪都在危险半径外、脚下踩得住且不伤人、身子过得去（一格高的台阶带跳）；都不行时挑"挨打最少"的那个方向。身后是墙就往侧面挪，不原地站着。
- **远处、隔墙、高低差大的**：寻路目标是"距离带 + 危险半径代价"（v0 `NavGoal.approachAvoiding` 与 `GoalAvoidEntities` 移植过来），寻路会自己绕开怪群。
- **被两侧夹住**：往开口方向退，让追兵排成一线、一次只面对一只；背靠墙对着开口打。
- **冷却与控距一起走**：冷却好了上前一步砍完立刻退回带子外沿；被击退、被推开也照样按带子收回来。
- **怪进了它够得着我的距离还在干别的活**：这是"立刻处理"（3.8），不等手上的活走到能停的地方。

#### 3.5.2 防苦力怕炸

现在的毛病：点着引信的苦力怕只算"尽快处理"，手上的活停不下来时插不进；躲的动作要先算寻路，引信只有 1.5 秒。v1 这样做：

- **引信点着（膨胀中）且在 7 格内 → 立刻处理**，压过一切（含点名战斗、血线撤离）。
- **先跑后算**：当刻就按背离它的方向疾跑（直接按键，用 3.5.1 的八方向挑一个能走的、离别的怪远的），不等寻路；跑不动（被挡）才交给寻路找别的路。跑到它的熄火距离（7 格）外，并且出了爆炸波及范围（普通苦力怕 6 格、闪电苦力怕 12 格，按 3.2）再停。
- **等它熄**：站在范围外看着它，膨胀退回零才算熄；熄了、手上有近战武器，再回去打。
- **没点着的近处苦力怕（8 格内、看得见）**：有远程先射；只能近战就"砍一下退一步"——砍完立刻退出 3 格点火距离，它重新逼近再砍，不贴着它连砍。
- **身边有别人的苦力怕在炸**（不是冲我来的）：同样躲出波及范围。
- **被炸了**：如实记进 hurt 事件（谁、掉多少），护甲碎了按 3.4 重新评估。

**手（出手、拉弓、举盾）**：每刻独立判断——够得着（3.2）且充能 ≥ 0.95、目标不在受击无敌、换手后已稳定一刻 → 原生攻击；拉弓时脚照走；冷却中、对手在近处 → 举盾，要挥了先放。出手前把挑好的武器换到主手（第十九轮已有）。不疾跑时出手（疾跑会取消原版暴击）。

**武器（`Loadout`）**：按物品类与属性认，不看 ID 后缀——剑、斧按物品标签与攻击属性，弓弩按 `ProjectileWeaponItem`，加上重锤、三叉戟；近战分 = 攻击伤害 × 攻速 + 对这个目标的加伤；对手举盾斧优先；混在羊群里避开剑的横扫。远程：上了弦的弩 > 联动远程（土豆加农炮）> 有箭的弓 > 能装的弩。

### 3.6 卡住：按原因换办法，不按计时

| 现象 | 处理 |
| --- | --- |
| 寻路说走不到这只（悬崖对面、高台上） | 有远程就射；没有就撤销它的目标资格，换下一只；都打不着就结束并写明"够不着" |
| 站位到了够不着 | 3.5 的补站位；补不齐换格 |
| 看不见（隔墙） | 交给寻路绕；绕不过去同"走不到" |
| 原生攻击连续被拒（没确认命中） | 记一笔、换个角度再出手；连续 3 次都被拒才当"打不出去"结束这只 |
| 整场长时间没有任何进展（没出手、没位移、没射出一箭） | 兜底：30 秒后结束并写明最后卡在哪一步，不转撤离（撤离只由血线、打不过、爆炸触发） |

### 3.7 撤离（`Retreat`）

- **往哪跑**：以所有正在追我的怪的位置重心为反方向，±90° 内试 8 个方向、32 格外，挑已加载、脚下踩得住、身体两格空的落点交给寻路；寻路同样尽量不进危险半径（v0 `Haven`）。自卫撤离知道家（`remember` 记过的"家"，没记过就用打点）在哪时，这几个落点里挑离家最近的，走不通按离家远近换下一个；点名战斗不往哪边靠。
- **甩开**：32 格内没有正在追我的才算；只认这次参与了追击的与新近打过我的，远处没参与的怪不让这次逃跑无限延长（v0 `RetreatThreats`）。
- **承诺**：开始了就跑到甩开；身体真走出两格才清失败账；连续 3 次走不通才背水一战（第十九轮已有）。
- **途中被追上**：面朝它往后退，够得着就还手（已有）。
- **打不过又走不通、天黑露天**：转身迎战打到底（夜里不垫高），不原地熬到天亮；甩开了追兵仍在露天，由夜晚需求去备一张床来睡。
- 撤离不等于赢：目标没击败以 failed 收场，写明拒战线、差什么、怎样能再打。

### 3.8 自卫插曲（`SelfDefenseTask` 收成这一层）

- 触发同 3.3"正在追我"。急迫程度：
  - **立刻（NOW）**：引信点着的苦力怕在 7 格内；有怪已经进了它够得着我的距离再加 1.5 格（马上要挨打）；血线破了还在挨打。
  - **尽快（SOON）**：其余正在追我的。
  - 主任务就是 fight 且不是"打不过"时让它自己处理（已有）：怪贴脸、引信点着它用同一个引擎自己会退、会躲；只有血线破了本能接管，照样插自卫。
- 自卫没做成不缓：控制环对没做成的临时任务按次加倍缓一阵（最长 5 分钟），被攻击不吃这条——每一下新挨的打都要响应，缓着就是站着挨打（施工时"被打怎么也没反应"的根因）。撤离甩开了追兵记完成，写明为什么撤、离打点多远。
- 追击上限：离打点 16 格（水平）以外、**没在打我**的不追；正在压着我打的、射界里在射我的不受这个限制（修 1 表第 4 条）。
- 危险消失后观察 2 秒；打完离打点远就走回去，回不去暂停主任务并说明停在哪（已有）。
- 撤离甩开了追兵，天黑了、血也低：不停在野地里等下一只，撤离照常收场；夜里没床时由夜晚需求接手去备床睡觉。
- 人回不到打点时（撤离甩开、走不回去）：去某地、拿东西这类在哪做都一样的主任务（能力自己声明）从新地点接着做，两件事之间也一样；守着原地的（施工、挖指定的格）暂停，暂停事件和目标此刻在做什么里写为什么停、离打点几格、人停在哪。被陌生玩家打了照旧都停下等 LLM 决定还不还手。
- 开始、结束事件写打点、位移、红心差、暂停了哪个任务（已有）。

### 3.9 拾荒

点名战斗击败后捡身边掉落，统一用玩家行为层的 `PicksUpDrops`（v1 对照审查已指出战斗自己写了一套）；按拾取包认领，走不到的写明，不站着等尸体刷掉落。自卫打完只捡顺路的（不专门绕）。

### 3.10 玩家对战（恢复）

**结论：丢弃 PvP 不合理。** 角色在多人服务器上直播，被人打是常态；"被打既不还手也不停下也不说"比 v0 退步，"点名打玩家"也没有对手还击后的处理。恢复 v0 的三件，按 v1 的许可模型改写：

1. **对战许可**：LLM 点名一位玩家（`fight=any` + `seen` 编号或玩家名）= 本次目标绑定这位玩家的身份（UUID）。对手还击算继续交战；目标结束、暂停、取消、对手下线或重生即撤销，不继承给后来出现的同名实体。
2. **对战打法**：出刀节拍按武器攻速（换手先等一刻，切换目标不重置冷却）、远近切换迟滞、弓的距离带随对手逼近速度变（3.5 表）、对手举盾换斧、瞄准跟随横移但夹在对方碰撞箱内（v0 `PvpCadence`、`PvpTactics`）。拒战线与撤离同打怪。出刀节拍与瞄点提前量的细则在第 11 节，那里改了"夹在碰撞箱内"这一句。
3. **被没点名的玩家打**：立刻发 hurt 事件（已有，写明玩家名）；自卫只做"退到对方够不着外、举盾"，**不自动还手**；暂停主任务、等 LLM 决定（还手就下 `fight` 点名他；不理就恢复主任务）。实例配置里的自家人打我只发事件，不停工（多半是玩笑）。第 10 节第 2 项待定。

### 3.11 组合的模型

M2（走位与站位）、M3（原生攻击、拉弓、举盾逐刻确认）、M4（身上的武器与弹药）、M6（自卫需求、打断与插曲）、M7（许可：`permissions.fight`、点名即许可、自家人）、M8（进度、结果）、M12（观察编号、威胁扫描）、寻路（距离带目标 + 危险半径代价）。本域特有：几何、战场快照、决策、两层执行、撤离、对战许可。

## 4 能力说明

`fight` 参数不变（`target`、`entity`、`radius`、`count`、`permissions.fight`）。说明里改两句：

> 打谁、怎么打由 Mod 现场判断：够得着按双方身板算，冷却时退到对方够不着的地方等，有弓先射远的，对面举盾换斧，点着的苦力怕先躲。打不过或血见底就往没怪的方向撤，甩开了才停。点名打一位玩家需要 fight=any；对方还手会接着打，打完收手。被没点名的玩家打时角色只退开、举盾，并停下手上的事等你决定。

结果细节加：`weapon`（这场用了什么）、`hits`（确认命中次数）、`reach_issue`（有够不着的目标时写哪只、为什么），撤离时的 `retreat`（为什么撤、跑了多远、甩没甩开）。

## 11 近战节拍与瞄点提前量

> 状态：待批准（2026-10-28 起草）。

### 11.1 范围

- **包含**：近身打时离下一刀还差几刻、冷却中什么时候往回走、跳劈什么时候起跳；换了武器以后多久能出手；对着动的目标瞄点往哪边提前多少，射箭的提前量读同一份移动。
- **现在有的**：出手门槛按原版充能等到 0.95，目标受击红闪时不挥；走位环随"充能满没满"在冷却带与出手带之间切；弓的远近切换迟滞；对手举盾换斧。没有的：离下一刀还差几刻（走位与跳劈只看满没满）、换手后隔一刻（只靠充能读数间接挡，换手当刻有空子）、对玩家有效的瞄点提前。
- **涉及的现有件**（`origin/dev` 9a4c4c187）：游戏接口层 `Interaction` 的原生攻击门槛与镜头到位判断、`MeleeAim`（近战瞄点，61 行）；`behavior.combat` 的 `Battle`（700 行，只动近身打一段，加十几行，不到 800 行上限）、`JumpStrike`（102 行）、`LiveCombatHands`（116 行，有第二份 0.95）、`ArrowAim`（277 行，射箭的目标移动）。
- **不动**：两条距离带怎么算、弓的远近切换（7 格换弓、4.5 格换回）、举盾换斧、拒战线与撤离、被没点名的玩家打只退开举盾。
- **不做**：疾跑击退（W 键重按）；看对手挥手估他的冷却、掐着他挥完的空当进。理由见 11.10 第 8 项。

### 11.2 真人怎么打玩家

1.9 起每把武器都有攻击冷却：挥完一下攻击条从零往上涨，涨满要 20 ÷ 攻速 刻——剑 12.5 刻（0.6 秒）、铁斧 22 刻、重锤 33 刻、空手 5 刻。条没满就挥，伤害按 0.2 + 0.8 × 充能² 打折；充能过 0.9 才有暴击、疾跑击退和横扫。所以会打的人不狂点：条快满时往前一步砍，砍完退出对方够得着的地方，等下一轮。跳起来、往下落时砍是暴击（伤害 × 1.5），起跳要掐好，落下来那一下条正好满，慢武器要等得更久才跳。换一下武器攻击条从零重新涨，换完当刻挥出去那一刀也不按新武器算，所以打着的时候不来回换；真要换（对面举盾换斧）就认下这一轮的等待。对面在横移、在跑，就往他走的方向带一点再砍，不然准星老落在他身后。

### 11.3 新逻辑

```text
1 离下一刀还差几刻  充满要几刻 = 20 ÷ 攻速属性（读原版自己的数：武器、急迫、挖掘疲劳都算在里面）；
                   还差 = 向上取整((0.95 − 此刻充能) × 充满要几刻)，已够格为 0；
                   对手受击红闪还剩几刻也算进去，两样取大的；
                   主手刚换成另一种东西：这一刻不算够格，下一刻起按新武器从零充
2 冷却中站哪       还差的刻数 > 走到出手带外沿要的刻数 + 1 → 站冷却带（对方够不着外 0.35～1.2 格，举着盾）；
                   否则提前往里走，到跟前正好够格。走过去要几刻 = 差的距离 ÷ 每刻走多远
                   （按自己的移动速度属性折，平地走路约 0.22 格/刻；不按疾跑算，疾跑会吃掉暴击）
3 出手             够得着、够格、准星先碰到它 → 原生攻击。门槛照旧：充能 ≥ 0.95、它不在受击红闪里、
                   这一刻有交互机会；新加一条：主手换了种类以后至少隔一个客户端刻。
                   砍完攻击条清零，按第 2 步退回冷却带
4 跳劈             够得着、头顶有空、不是苦力怕：离下一刀还剩 7 刻以内起跳——平地起跳第 7 刻开始往下落、
                   第 12 刻落地，够格正好落在往下落的那几刻里；比 7 刻还快就充满的（空手）落地就跳。
                   落地时满条站着砍、两跳没砍出去就站着砍一阵，这两条照旧
5 瞄点提前         它的移动按本客户端看到的算：这一刻的位置减上一刻的位置；
                   提前 = （它的移动 − 我的移动）× 3 刻，水平最多 1 格，竖直按 0.75 刻算、最多 0.5 格；
                   一刻挪了 2 格以上（传送、末影珍珠）这一刻不提前；
                   瞄点仍取提前后的身体框里离眼睛最近、往里收一点的那一点
6 镜头到位         视线离瞄点 7° 以内，或准星射线已经先碰到它，都算到位；出手前照旧要准星先碰到它
7 射箭             弹道里目标的移动改读第 5 步那一份看到的移动，其余不变
```

组合的模型：M2（距离带走位，带子不变，只改什么时候从冷却带换到出手带）、M3（原生攻击的门槛加一条，到位判断放宽一条）。本节特有的：离下一刀的刻数、提前起步、跳劈的起跳时机、瞄点提前量。

为什么这样定：

- **第 2 步**：打玩家时两边手一样长（交互距离都是 3），没有"我够得着他够不着"的缝。冷却带在他够得着外（中心距约 3.65 格起），出手带在我稳稳够得着内（约 3.15 格内），中间差半格到一格多，走路要两到六刻。现在条满了才起步，剑一轮 12 刻里白等这几刻，他一步上来先砍到。打怪时两条带本来重合在"我够得着它、它够不着我"的那条缝里，走位几乎不变。
- **第 4 步**：现在充能过半就跳。剑过半起跳后第 6 刻满，正好往下落；铁斧过半起跳要第 10 刻才满，只剩一两刻能砍；重锤落地了还没满，只能站着砍。按刻数起跳，剑几乎不变，慢武器也能落下来砍。
- **第 5 步**：原版不把玩家的速度同步给别的客户端（只有被击退、滑翔时发），角色这边读到的别的玩家速度几乎总是零，现在的瞄点提前与射箭提前对玩家都不起作用。看到的位置倒是每刻都在动（服务端两刻发一次位置，客户端分三步插过去），前后一减就是他的移动。提前 3 刻是补角色自己的镜头：镜头像真人一样平滑转（约 0.11 秒，对着动的目标稳定落后约 2 刻的位移），瞄点每刻又只跟过去 55%（再落后约 1 刻）。3 格外疾跑横移的玩家（每刻 0.28 格）不提前时，视线落在他身后 0.8 格左右，是半个身宽的两倍多，一刀都砍不到；提前 3 刻正好补回来。镜头落后的是角色和目标之间的相对移动，所以减掉我自己的移动。打怪时镜头一样落后，用同一个提前量。
- **第 6 步**：提前以后镜头对着的是他此刻的身体，离瞄点本身还差约 2 刻的位移（3 格外疾跑横移约 12°），按 7° 判就一直"镜头还没转到"。准星已经落在他身上，这一刀就打得中。
- **换手隔一刻**：原版每刻看一眼主手，换成另一种东西就把攻击冷却清零（换成另一把同样的剑不清）；服务端要到这位玩家下一次实体刻才换上新武器的攻击属性，换手当刻挥出去那一刀可能按旧东西算。隔过一刻以后，客户端自己的充能也已经清零，第 1 步自然等到新武器充满。

### 11.4 能力说明

`fight` 的参数与结果字段都不变。能力说明里近身走位与点名打玩家两条改成：

> 冷却中退到对方够不着的地方等，快好时提前往回走，到跟前正好砍；跳劈按武器快慢掐起跳，斧子、重锤也能落下来砍；换了武器先等它的攻击条回满再砍。对着横移、跑动的人会往他走的方向瞄一点，射箭也一样。

### 11.9 验收

**离线**（判断写成纯函数，替身给数，不用 `Unsafe`、不反射改私有成员）：

1. 离下一刀：剑（攻速 1.6）充能 0 → 12 刻；铁斧（0.9）→ 22 刻；重锤（0.6）→ 32 刻；空手（4.0）→ 5 刻；充能 0.95 或 1 → 0；对手红闪还剩 8 刻、充能只差 3 刻 → 8 刻。
2. 换手：主手这一刻换成另一种东西，读数是满条也不够格；下一刻起按新武器从零算；换成同种东西（另一把铁剑）不受影响。
3. 提前起步：打玩家（两边交互距离都是 3），站在离他 4 格的冷却带里，离出手带外沿差 0.85 格（走 4 刻）：剑还差 10 刻 → 不往里走；还差 6 刻 → 不往里走；还差 5 刻 → 往里走；够格了 → 往里走。打僵尸时同样的场景，走位一步一步和改前一致。
4. 跳劈：剑、铁斧、重锤在离下一刀 7 刻时起跳，够格那一刻都落在起跳后第 7～11 刻（往下落）里；空手落地就跳、往下落时已满；离下一刀还有 8 刻不跳。
5. 看到的移动：这一刻比上一刻挪了 0.28 格 → 读 0.28；挪了 3 格 → 当传送，这一刻不提前。
6. 瞄点提前：3 格外、他横移每刻 0.28 格、我站着 → 身体框往他走的方向挪 0.84 格；每刻 0.4 格 → 挪 1 格（到上限）；我和他同向同速横移 → 不挪；他跳起每刻往上 0.42 格 → 竖直挪 0.32 格，再快也不超过 0.5 格。
7. 镜头到位：视线离提前后的瞄点 12°、准星射线先碰到他 → 到位，出手；同样 12°、准星没在他身上 → 不出手，照旧记"镜头还没转到"。
8. 射箭：目标看到的移动是每刻 0.28 格（读数里速度为零）→ 弹道往他走的方向提前；他站着 → 与改前同一条弹道。

**实机**（要两个玩家：开发服务端，开发客户端上是角色，另开一个客户端用另一个离线名字当陪练、由人操作；先占"实机"）：

0. 准备：白天、平地、难度简单。角色快捷栏放铁剑，主背包放铁斧，一身铁甲，副手盾；陪练一身铁甲、铁剑、副手盾。两人相距 8 格。LLM 先 `observe` 拿到陪练的观察编号，下 `fight` 点名他，`permissions.fight=any`。全程看日志里的 `[战斗]` 与 `[近战]` 两类。
1. 陪练站着不动、不举盾：角色砍一刀退开一点，条快满时往回走，到跟前就砍。连着十刀，刀与刀间隔在 12～15 刻（0.6～0.75 秒）；多数是跳劈（看得到暴击粒子）；`[近战]` 里除"攻击条还没回满"外没有别的等待原因连着刷。
2. 陪练按住 A（或 D）绕着角色走一圈，再疾跑绕一圈：角色照样打得中。同样时长下结果里的 `hits` 不少于第 1 步的一半；"镜头还没转到"不连着出现超过 1 秒。
3. 陪练正面举盾：角色把斧子换到手上（在主背包就开背包换）；日志里换手那一刻没有出手，换完约 22 刻才出第一刀，这一刀让陪练的盾进冷却（盾的图标变灰 5 秒）。
4. 陪练转身疾跑跳着逃出 15 格再停：角色追上去，追到够得着才挥，路上不对着空气挥；停下以后照第 1 步那样打。
5. 把角色的武器换成重锤（没有就用木斧）重做第 1 步：跳劈落下时出暴击，而不是每次都落地后站着砍。
6. 陪练退到 10 格外拿弓射角色、左右跑动：角色换弓对射，箭落在陪练前进方向上，不老落在他身后。
7. 对照：同样装备点名一只僵尸：一刀一退、不贴脸，和改动前一样，刀与刀间隔不比改前长。
8. 陪练停手站着、或下线：角色打完收手，或以 `TARGET_GONE` 收场（已有行为不变）。
