# 领域规格：探索

> 范围：能力 `explore`（往某个方向勘察地形）：有界跑图与群系发现、途中留意清单、方向性找平台、回露天地面。里程碑二。钻进矿洞顺着走、一路看矿（`target=cave`，连同感知认洞口、回地面时近了走回洞口）在第 11 节，待批。
> 依据：[探索与寻找-旧逻辑清单](探索与寻找-旧逻辑清单.md)（E 组 42 条；v0 `dev` 基线 `aa97940c9`）与[出行-旧逻辑清单](出行-旧逻辑清单.md)的 T-42、T-49、T-50、T-51；v0 源码另核对过 `RegionalTravelTask`、`TravelSurfaceTask`、`RegionalGoal`、`ExplorationSector`、`ExplorationFrontiers`、`FrontierLegBreaker` 与探索记忆三件。出行与寻找-规格已定：走动搜索随探索一起做，群系发现归探索；被它推迟到本规格的条目在这里定做法。
> 边界：`find` 已在出行与寻找-规格里（里程碑一只扫已加载区），本规格不重复它的扫描与视线纪律，只定"附近没有、要走远点找"归谁（定下的做法 3）。每段走行交给走到，跨水、上坡、垫料、换气、中途停下复用出行规格已定的行程保证，不重写。跨维度归出行补齐规格，本规格不碰；探索中换维度如实结束。乘船、喷气背包、飞行器、电梯归载具域（原版乘船在里程碑四；喷气背包、飞行器、电梯 2026-10-11 随 Create 并进里程碑三），以 UNSUPPORTED 如实说明。发现写进 M9 世界记忆，存储与查询归世界记忆，本规格只定来源标注（定下的做法 5）。
> 说明：第 5 节"内容"描述的都是 v0（`dev` 分支）的做法；v1 按本规格重写，不移植这些文件。条目编号沿用两份旧逻辑清单；出行与寻找-规格已归类的条目不重复列出。

## 2 真人怎么做

想看看某个方向外有什么，就朝那个方向走，边走边看：没走过的群系、岩浆湖、村庄、矿井入口，看见了都记下，回头说得出"东北三百格外有个村庄"。说好跑多大范围就跑多大范围，到了范围边上收工，不为了多看两眼一头冲出去。复杂地形走不动，先横着挪一段换个地方试，再换个方位，全都试过才承认"这一片走不出去"，而且说得出试过哪些。想找块平地放东西，就朝指定方向找一处能站人的平地，到了先看看脚下四邻是不是真的平。在矿道里待久了要回地面，就往上挖；头顶盖着水就不硬钻，换个地方。顺路留意的东西看见了就记下，不为它扔下正事，也不站在原地等人来问。

## 3 新逻辑

### 3.1 目标与"界"

```text
探索目标（参数 target，一次只认一种；坐标这类已定位终点不接受——探索没有预设终点）：
  survey            自由跑图：没有预设目标，把这一片看清、走到范围边就算完成，
                    不把脚下的群系当作抵达
  群系 id / #标签    定向探索：走到该群系里能站（或能游）的格子、核实脚下群系才算抵达；
                    注册表里没有的群系以 UNSUPPORTED 结束，提示先 lookup 查可用 id
  platform          找平台：必配 direction，走到"脚下与四邻至少 3 格同高支撑"的格子，
                    站上去后复查判据，不只凭采样宣布到达
  surface           回露天：回到"这一列忽略树叶的最高实体或液体遮挡物正好在脚底"的地方；
                    授权动土且明显被埋（所在列顶盖高于脚下）时先沿本列竖直上掘到顶盖再破出，
                    顶盖是液体或非实体方块就跳过上掘、记下原因照走地面流程；未授权被埋时
                    如实结束，建议里写明"授权动土就能上掘"；未加载的列既不判露天也不判
                    封闭，先走近加载再采样
  结构编号不作探索目标（定下的做法 1）：结构要线索与到场确认，与群系的抵达判据不是一回事；
  沿途看见的结构线索记入世界记忆，LLM 决定要不要去看

"界"的表达：
  max_distance       探索半径，64..2048，默认 768：候选不越过它；身体进入 max_distance−容差
                     （容差 = min(8, 半径/8)）即到达半径，成功收尾并取消在途段；
                     越过 max_distance+8 硬边界截停失败，如实写明越界，不冒充无路、不冒充达成
  direction          扇形朝向（可选）：与目标对象 direction 同一套八向词（定下的做法 6）；
                     出发时按当时视角换算成罗盘方位并固定，之后转头不改变搜索方向
  angle_degrees      扇形开口角 1..360；有方向默认 90，无方向必须省略或 360
  min_distance       起找距离：忽略更近的匹配；有方向默认 16（先离开脚边，避免没出发就用
                     所在群系完成跑图），无方向默认 0
  max_seconds        最多做多久（秒）；观察与走行有真实进展就续期，不因排队烧期限
```

参数互斥与范围在参数校验阶段一次报全，不进游戏：一次一种目标、无方向不给开口角、起找距离不超过半径、半径在 64..2048 内。

### 3.2 观察与推进

```text
以当前位置为圆心逐列抽样（观察圈半径 112 格，每刻一批，跑完为止）：
  沿途记群系与地形要素（岩浆湖）；身体所在群系免视线闸直接记（到访），
  远望样本必须过视线闸——已加载不等于看得见
  定向探索沿高度自上而下找目标群系的可站/可游样本；找不到落脚格的深层样本只计数，不出发
目标候选：在扇形内且视线可见才出发；扇形外或看不见的只记不追——较近的侧后方证据
  不能替代指定方向上的目标，也不能凭已加载的地下样本导航进去
到达候选后按脚下事实复核（群系、扇形）；复核不过把候选记入拒绝集、记一段失败，回观察；
  失败候选不再反复尝试
观察分刻推进，抽样期间逐刻续期；发现聚类未结算时驻留有上限，不无限等
探索中切换维度 → 如实结束，旧范围作废
```

### 3.3 航点与走行段

```text
没有候选、或候选走失败 → 起航点航段（航点选择，纯判断）：
  有方向：扇形内 17 条射线 × 80→16 格距离打分，选已加载的新落点；
    得分 = 离原点距离 + 距离×0.2 − 射线偏心×0.1
  无方向：方形螺旋外扩，沿途截取最远 80 格的已加载路段
  穿水候选整体让位，全部候选都穿水（身处岛屿）仍选得分最高的——穿水是优先级不是否决，
    渡不渡得过去由走到的跨水保证结算
  16 格内已试过或已证实走不通的邻域不再选；落点列是纯水面的不选（实机 175）
  航点上限由半径推出：覆盖范围由目标区域决定，不是尝试次数上限
每段走行交给走到（M10）：
  到达确认、跨水、上坡、垫料、换气、中途可停都是出行规格已定的行程保证；许可里的
  change_blocks 决定能不能挖垫，目标探测本身永不改方块
  段走行的滞水守卫由走到的行程守卫承担；守卫判弃 → 本段按失败进入换向升级
行进中达成目标（核实通过、到达半径）→ 立即取消在途段收尾，不走过头
被叫先到安全处再停（暂停、取消，不急的需求一直等不到空当）→ 转给这一段走路：悬在半空的先落地，
  落地报的"已停下"不算走到，原地等着；接着做时这一段从原地续走，不把半路落地的地方当成走到的航点或候选
```

### 3.4 换向升级

```text
换向升级（纯判断，读最近走行段的成败）：
  最近 5 段（成败都算）失败满 4 次 → 升级；触发看观察窗占比，不看严格连续——
    偶发到达清零连续失败，会掩盖出发点地形本身不可行
  先换出发点：垂直于当前方位 ±90°、约 32 格、截已加载路段，至多 2 次——沿崖壁、
    水线这类条带地形横移，比迎着同一面障碍换角度更容易找到出口；
    换出发点这段自身失败就直接走下一级，不在坏出发点周围再烧一整窗
  再轮换扇形：顺时针 45°，至多 7 次（八个方位试遍）；全向跑图没有可轮换的方位，只剩换出发点
  耗尽 → 受阻：如实结束，受阻说明一次写清连续失败量、卡住的方位、换出发点与轮换历史，
    建议远距换区或授权动土；受阻不是"目标不存在"的证据
窗口、次数与换出发点距离实现时定初值，按实机观感调整
```

### 3.5 收尾与结果

```text
定向探索：核实通过 → done，交付核实位置；查完范围没核实 → NOT_FOUND，
  写清只搜了真实加载的地形（"查过没有"不等于"世界里没有"）
自由跑图：进入半径判定带 → done；能走到的外围都走过而预算耗尽 → done，如实写明；
  没到过任何航点 → failed
越界截停 → failed，独立写明原因（一次跳出去不冒充达成，也不冒用无路）
受阻 → UNREACHABLE；卡住与超时按 M8（STUCK）
生存需求的临时任务没做成，不把探索判失败（M6）
```

### 3.6 途中发现与世界记忆

```text
跑图的发现写 M9 世界记忆，来源标注分两档（定下的做法 5）：
  到访      身体到过并核实：脚下群系、站上平台、破出露天、走到结构跟前
  亲眼看到  远望：只看得见、没到跟前（群系样本、结构线索、岩浆湖，一律过视线闸）
同一条发现重复看见合并成一条；远望的记录到了之后升级成到访，不降级、不重写
结构线索只按线索记入产地线索种类，证据组合符合不冒充到访；设施照感知的既有纪律入记忆
发现同时进跑图结果；要不要在途中通知 LLM 见定下的做法 4
发现过的位置以后叫得出、去得了：世界记忆里有了地点，travel 的 landmark 解析就能到
```

### 3.7 组合的模型

M1（总流程）、M6（途中生存需求：走行中正常干活，等确认与滞水时停下不安全，两段之间可插）、M7（change_blocks、受保护格不入走行）、M8（进度跟踪以观察统计与身体推进为进展信号、结果、attempts 记换向历史）、M9（发现入记忆、来源标注）、M10（走到、行程保证、高度纪律）、M12（场景、观察编号、视线闸、地形特征与设施）。

本域自己特有的：目标与"界"的表达、观察推进、航点选择、换向升级、半径收尾、平台与露天判据、发现落账。

## 4 能力说明（参数与结果）

参数名用参数名表里的；本规格新登记 `interests`、`angle_degrees`、`min_distance`（见末尾）。

### `maicraft:explore`

| 参数 | 必填 | 说明 |
| --- | :---: | --- |
| `target` | ✅ | 探索目标：`survey` 自由跑图 / 群系 id 或 `#` 标签 / `platform` 找平台 / `surface` 回露天。不是目标对象，探索不接受已定位终点（见定下的做法 1） |
| `direction` | platform 必配，其余可选 | 扇形朝向：`forward` / `backward` / `left` / `right` / `north` / `south` / `east` / `west`，出发时按当时朝向固定 |
| `angle_degrees` | | 扇形开口角（度），1..360；有方向默认 90，无方向必须省略或 360 |
| `min_distance` | | 忽略更近的匹配（格）；有方向默认 16，无方向默认 0 |
| `max_distance` | | 探索半径（格），64..2048，默认 768 |
| `max_seconds` | | 最多做多久（秒） |
| `interests` | | 途中留意清单：`lava_pool` 这类地形要素、结构 id，要不要扩方块与实体见定下的做法 3 |

可给 `permissions`：`change_blocks` 决定走行能不能挖开、垫方块，以及回露天被埋时能不能上掘（默认 `natural`）。

能力说明：

> 朝某个方向把外面的地形跑一遍：自由看看这一片有什么，或去找一种群系、一块能站的平地、回露天的地面。说好跑多大范围，到了范围边上就收工；路过的群系、岩浆湖、村庄线索都会记下来，之后叫得出名字、去得了。地形走不动会自己换地方、换方向试，全试过才如实说卡住。走一段要挖土垫路时看许可，默认可以动天然方块。找具体的东西用 find（只看附近）；附近没有时先 explore 再 find。

本能力特有的结果细节：

| 字段 | 含义 |
| --- | --- |
| `findings` | 途中的发现：种类（群系/地形要素/结构线索/设施）、目标 id、位置、到访还是远望 |
| `reached` | 定向探索核实到的位置（x/y/z 与维度）；没核实不给 |
| `stop_reason` | 怎么收的尾：`radius_reached` 到达半径 / `frontiers_exhausted` 能走到的外围都走过了 / `left_bound` 越界截停 / `blocked` 受阻 |
| `coverage` | 观察统计：观察列数、最远的身体与观察距离、未加载边界的样本 |
| `origin`、`sector` | 出发点与实际生效的扇形（含换出发点与轮换的方位历史） |
| `legs` | 走行段统计：几段、失败几段 |

## 9 验收

**离线场景测试**（判断类用替身接口，任务用动作替身，不使用 `Unsafe` 与反射）：

1. 参数与目标：四种目标写法各一例；一次给两种、无方向给开口角、起找距离超半径、半径出界 → 参数校验一次报全；群系 id 认不出 → UNSUPPORTED。
2. 扇形：相对方位按出发朝向换算并固定；默认开口角与起找距离；候选只在扇形内，扇形外证据只记不追。
3. 半径收尾：进入判定带成功收尾并取消在途段；越过硬边界截停独立如实报告；航点不越过判定带（实机 165 场景）。
4. 航点选择：打分与穿水让位、全穿水仍选出；已试 16 格邻域去重；纯水面落点不选（实机 175 场景）；上限由半径推出。
5. 换向升级：5 段 4 败触发；换出发点 ±90°、自身失败直接下一级；45° 轮换至多 7 次；受阻说明含全部历史（实机 075/093 场景）。
6. 找平台：平台复核（脚下与四邻 3 格同高）不过不算到达。
7. 回露天：露天判据（树叶不算遮挡、未加载先加载）；被埋且授权动土先竖直上掘；顶盖为液体/非实体跳过并记原因；未授权时失败建议写明出路。
8. 发现与记忆：到访免视线闸、远望过闸；重复发现合并、远望升级到访不降级；结构线索只按线索记、不冒充到访。
9. 观察推进：抽样分刻续期不烧期限；换维度如实结束。
10. 先到安全处再停：段走行悬在半空被叫先停稳 → 落地才算停稳，落地不当成走到、不去到场复核；暂停后同一段从原地续走走到候选；站在地上走着 → 现在就能停。

**实机验收**（追加到里程碑二清单；含第 5 节 P/G 类的原事故场景）：

1. 平原让它自由跑图 256 格 → 走到范围边附近收工，结果写到达半径；沿途群系进世界记忆，observe(world_memory) 看得到（实机 091 同场景看岩浆湖）。
2. 让它朝一个方向找指定群系 → 出发后调转视角，搜索方向不变；走到后站实，结果带核实位置。
3. 复杂出发点（崖壁、水线）让它定向探索走不到的目标 → 换出发点、轮换后要么走出去要么如实受阻并说清历史，不原地空转（实机 075/093）。
4. 湖泊、河流地形跑图 → 不把身体领进深水长泅；短促渡水能过，滞水守卫生效换向（实机 073/130）。
5. 让它向前找一块能站的平台 → 站上的地方四邻至少 3 格同高支撑。
6. 在地下矿道让它回露天 → 授权动土时竖直上掘破出；头顶是水时不硬钻、换地方；结果写明露天证据的列高。
7. 跑图路过村庄 → 结构线索入世界记忆且来源是远望；让它走过去后升级为到访（实机 103 场景看沿途记录）。
8. interests 给岩浆湖 → 途中发现进结果与世界记忆，任务事件有一条发现通知（按定下的做法 4 的方案验收）；角色不因发现停在原地（实机 145 的冻结与重提不再出现）。
9. 目标群系在半径边界外 → 不越过硬边界追，截停如实报告只搜了半径内的已加载地形（实机 165）。
10. 跑图途中正跳过一道坎、或垫方块爬坡到一半时暂停目标 → 落地站稳才停；恢复后朝同一个航点或候选接着走，不把半路停下的地方当成走到。

## 10 定下的做法

| # | 问题 | 做法 |
| --- | --- | --- |
| 1 | explore 的目标形式：四种目标写法与参数名 `target`，`coast` 别名与结构编号要不要保留 | 按 3.1 定：`target` 取 `survey` / 群系 id 或 `#` 标签 / `platform` / `surface`，能力说明写明它不是目标对象、探索不接受已定位终点。`coast` 别名不要（海岸就是 `minecraft:beach`，少一个专用词）；结构编号不作探索目标——结构的抵达要线索与到场确认，与群系不是一回事，沿途线索记入世界记忆即可，v0 把结构目标转投搜索也是同一个理由 |
| 2 | 方向性找平台与回露天地面收不收进 explore | 收进，作为两种目标写法（`platform` / `surface`）。它们都是"没有精确终点、按判据发现并核实"的活，和探索一个形状；travel 已定不带发现类目标。判据与竖直上掘按 3.1；喷气背包兜底随里程碑三（2026-10-11 随 Create 并入） |
| 3 | "走动搜索"怎么落：explore 的留意清单（interests）要不要扩到方块与实体 | 扩。既定方向是走动搜索随探索一起做：interests 可给方块 id/标签与实体类型，途中看见（过视线闸、在扇形内）就记入世界记忆与结果，不因它改路线、不算抵达主目标。"找 N 个"仍是 find（已加载区）的事；附近没有时 LLM 用 explore + find 组合。这样不给 find 开"走动"口子，找保持纯观察；代价是 interests 的合法值要登记。备选是 explore 另开"找东西"目标或维持 LLM 手动组合，都比留意清单厚 |
| 4 | 途中发现怎么告诉 LLM：任务事件推送、发现即问、还是只进结果 | 任务事件：events 增加一种 kind（`discovered`），带发现摘要；角色不停、不问，LLM 想改主意随时暂停或取消。v0 的发现即问要在 M8 三种提问原因之外开口子，还带来决策状态机与补期特例（实机 145）；只进结果则跑图十几分钟里 LLM 全程不知情。代价是 07 的 events kind 表加一项 |
| 5 | 探索发现的世界记忆来源标注 | 记忆来源加一档"到访"（`VISITED`）：身体到过并核实；"亲眼看到"（`SEEN`）收窄为远望。重复发现合并成一条，远望到了之后升级成到访、不降级。群系与地形要素记入产地线索种类（内容写清是什么），不新增记忆种类；合并与升级的存储策略归世界记忆，全仓一份 |
| 6 | 扇形方向的词表：目标对象 direction 的八向词加开口角，还是保留 v0 的十二方位 | 八向一套。方向词全接口只有一个来源（目标对象 direction 的 toward）；要斜向就给相邻方位加大开口角（最大 360）。十二方位是第二套词；45° 的方位差由换向升级在内部用角度表达，不需要暴露 |

## 11 钻洞：顺着矿洞走、一路看矿、近了走回洞口

> 状态：2026-11-02 批准（第 11.10 节五条都按推荐定），已实现；实机没跑。
> 范围：三件事。① 感知认得出看得见的洞口与峡谷，给 f# 编号；② `explore` 多一个目标 `cave`（钻洞）：从脚下或最近的看得见的洞口进去，顺着洞走，一路看矿；③ 回露天地面（`travel` 的 `here`）离记下的洞口近就走回洞口，远了照玩家平常的出法（就近找见天的地方、往上挖楼梯），不倒着重放来时的路。
> 起因：找矿现在只有两条路，长程挖矿和挖看得见的矿；矿透、服务端给方向都不做，观众一看就知道。玩家还有第三条路：钻天然矿洞，洞壁上露着的矿多，走着就看得见。采矿技能让 LLM "先去洞穴、峡谷"，可它不知道洞在哪；到了洞里没有顺着走的能力；走深了不许动土时，回露天只找 64 格内见天的落脚处，出不来。
> 边界：钻洞不挖矿，挖还是 `obtain`（看得见、够得着的才挖）；钻洞自己不改方块，走到按许可挖路、垫块照旧。找矿不放宽"不透视"：矿只认这一眼真看得见的。

### 11.1 真人怎么做

站在地面上扫一眼：山坡上一个黑窟窿、地上一个往下的口子、一道又长又深的裂谷，都是能下去的地方。走到洞口往里看，走进去，走到能看见的最远处，停一下左右看看洞壁上有没有矿；岔路先挑没走过的那条，走到底是死胡同就回头走另一条。前面是岩浆、地下水、跳不下去的深坑就不往那边去，记着"那边有岩浆"。一路插火把，看见要找的矿就走过去挖。出来的时候，离洞口不远就走回洞口；钻得远了不原路摸回去，就近找个见天的地方，或者往上挖一道楼梯出去。

### 11.2 认洞口：地形特征多两种

```text
洞口     看得见的通往地下的开口：
           开口格 = 能进人的空格（脚、头两格都能过），头顶有遮挡（不见天），挨着见天的空气；
           从开口往里沿能进人的空格量，连着一片暗处（天空光不到 8 的空格）至少 24 格才算洞；
           崖檐下、树底下浅浅凹进去几格的不算（里面不够暗）
         开口格要从眼睛看得见（过视线闸，与 find、采掘同一套遮挡判断）；墙后的洞、拐角后的洞不报
         同一个洞挨着的开口（6 格内）合成一处
         位置：离角色最近的那个能站的开口格，真实高度——travel 拿 f# 就走到洞口站定
         规模：往下（暗处大多在开口 4 格以下）或往里（横着进山）；不报有多深——往里只量到 512 格为止，
           说不出整个洞多大，只说"连着一片暗处"
峡谷     见天的又长又深的沟：
           地表（忽略树叶的最高遮挡物）比两侧 8 格内都低 10 格以上的列，四邻相连成片，最长那一向 ≥ 16 格；
           短的照旧是落差；同一处报了峡谷就不再报成落差
         沟底或沟壁至少一格从眼睛看得见
         位置：离角色最近的那一格沟底（能站的格，真实高度）；规模：长约几格、深约几格
扫描     水平 32 格、上下 24 格，只读已加载的区块；分刻扫，一圈约两秒，不占满一刻
         （俯视网格只看 8 格，洞口要远一点就看得见）
往里量   只用来判断"是不是个洞"，不报里面有什么，不拿它找矿、不拿它判断洞往哪走得通
记忆     看见的洞口、峡谷按产地线索记进世界记忆（内容"洞口""峡谷"，来源亲眼看到），同一片只留一条；
         observe(world_memory) 看得到，以后叫得出、去得了
```

天空光是游戏本身的光照数据（露天的格是 15，往遮挡下面每走一格少 1），客户端照常收到；暗处没火把的提醒已经按它认"头顶遮住的暗处"，这里用同一条事实。

### 11.3 钻洞：`explore(target=cave)`

```text
起步     脚下这一列头顶不见天、从脚下量得到暗处 → 已经在洞里，就地开始
         否则（在地面上，或在没有暗处的屋里）→ 挑最近的看得见的洞口（11.2 同一份判断；
           给了 direction 就只挑扇形里的），走到开口站定再开始；峡谷不当洞口挑，要下峡谷用 travel(f#)
         看不见洞口 → NOT_FOUND：说清看了多大范围（水平 32 格、上下 24 格），
           建议先 explore 跑一跑再看、或用 obtain 长程挖矿；"附近看不见"不等于"附近没有"
         开始的那一格记下：走到的洞口进世界记忆（到访）；就地开始时脚下就是开口格、或 8 格内看得见一个洞口，
           当作从那个洞口进的，同样记进去；都不是就记出发点，不进记忆。都进结果的 entrance，max_distance 从它量
         身上没火把照常走：暗处没火把的提醒照旧会说，不因此拒绝
一段     看一眼 → 挑下一段 → 走过去，反复
看一眼   站定转头扫一圈（左右各约 90°，略低头再抬头，约两秒），扫的同时做三件事：
           看矿    #c:ores 下的方块（原版矿与挂了这个标签的模组矿），加上留意清单里的方块：
                   过视线闸，还要看得清才算：够亮——露出来的那一面挨着的空气格亮度至少 4（方块光与天空光取大，
                   夜里天空光按天色减；火把、岩浆、发光方块照到的都算），或者够近——离头不超过 2 格（贴脸认得出轮廓）；
                   洞里没插火把的黑地方，远处的矿屏幕上是一片黑，不算看见，插了火把照亮了才看见；
                   亮度 4 是因为默认亮度设置下，亮度 4 的方块在屏幕上约有满亮的两成，矿石的斑点认得出来，
                   再暗一档只剩一成多，和洞壁糊成一团黑影；
                   同种相连的算一条矿脉，记块数和离角色最近的那一格
           看危险  看得见的岩浆按地形要素 lava_pool 记（与跑图同一条，浇门用得上）；岩浆自己发光，不看亮度
           量路    从脚下沿能站的格泛洪，水平 24 格、上下 16 格、最多 4096 格：
                   平走、上下一格算连通；许可能动土（change_blocks 不是 none）时往下跳不超过 3 格
                   也算连通（回来时走到会垫块或挖台阶）；不许动土只认上下一格，走进去的地方都走得回来；
                   挨着岩浆一格的、水里的不算能走（和俯视网格的"谨慎"同一条）；
                   泛洪边上挨着水、岩浆、往下超过 3 格的落差，记成"那边过不去"（什么挡着、在哪）
         转头只是让观众看见它在找：视线闸本来不看朝向，扫完这一圈才报"看见了"，观众看到的和报的一致
挑下一段 候选：泛洪到的、能站的、从眼睛看得见的格，离走过的地方 6 格以上（新地方）；
         打分：越远越好（走到能看见的最远处）、顺着上一段的方向（不来回折返）、给了 direction 偏向那个方位；
           离 entrance 越远略加分（往深处走）；界外（离 entrance 直线超过 max_distance）的不挑
         挑分最高的走；别的方向上的新候选按方向合并成"没走的岔路"（方位、距离、高低）记下
         眼前看不见新地方 → 去最近的没走的岔路（交给走到，路是已经走过的那片）；岔路也没了 → 这片洞走完了
         不看拐角后面：挑哪边只看眼前看得见的东西（多远、新不新、顺不顺路），不看拐角后面还有多长、
           是不是死胡同、哪边有矿——死胡同走进去看见了再回头，和玩家一样
走过去   交给走到，按这次的许可（默认 natural：走到可以挖一两格路、垫块过小坑）
         走到 → 下一段；走不到 → 记一段失败，这个候选 16 格内不再挑，回"挑下一段"
         路上随行补光照常插火把（钻洞是沿路走的任务）；怪物、饿了照常插在两段之间，回来从原地接着
留意清单 给了 interests：看见清单里的东西（过视线闸）→ 走到够得着、看得见它的地方站定，收场，
           结果写它在哪；接着 obtain 就挖得到
         没给：走到收场，一路看见的矿都记下
收场     看见了留意的东西 → done（interest_seen）
         这片洞走完了 → done（frontiers_exhausted）
         这一趟走满 256 格路 → done（walk_limit）：结果写还有几条没走的岔路；再钻一次接着走，走过的不重走
         离 entrance 直线到 max_distance（钻洞默认 128）→ done（radius_reached）：候选本来不挑界外的，
           走到判定带就收场
         一段都没走成（第一段的候选全走不通）→ UNREACHABLE（blocked），说清试了哪几处、为什么
         换维度 → 如实结束；卡住、超时按 M8（STUCK）
         收场时不自己往回走：留在原地（多半就在矿跟前），回地面用 travel(here)
结果     findings     矿脉（种类、块数、最近一格、远望）、岩浆湖、洞口（到访）
         entrance     洞口位置（就地开始时是出发点）
         branches     没走的岔路：方位、距离、高低；"那边过不去"的也在这里，带上挡着的是什么
                      （水、岩浆、往下几格的落差）
         legs         几段、失败几段、这一趟走了多少格
         stop_reason  见上
         summary 末尾说一句"回地面用 travel(here)：离洞口近会走回洞口，远了就近找见天的地方或挖楼梯上去"
进度     走到新地方、看见新矿脉算真实进展；半分钟没有就卡住（同跑图）
打断     与跑图同：两段之间可以插；走在半空被叫停先落地站稳，落地不当成走到
```

### 11.4 回地面：近了走回洞口，远了照玩家平常的出法

```text
记       钻洞进洞时记下洞口（11.3 起步）：世界记忆里的产地线索，内容"洞口"，来源到访
         走过的地方：钻洞时每挪 2 格记一个点，挑新地方时离它 6 格内的算走过；
           几次钻洞之间留着（再钻一次不重走），换维度清空；最多 4096 个点，满了丢最早的
         不记来时的路，也不倒着重放走过的格子
用       travel(here) 在地下时，顺序改成：
           0 已在露天 → 完成（不变）
           1 旁边几步就见天 → 走出去（不变）
           2 走回洞口（新，近的）：世界记忆里有到访过的洞口、离脚下直线不超过 48 格 →
               交给走到正常寻路去最近的那个（一次一个目标，按这次的许可）；
               走到了脚下露天 → 完成；洞口外面还盖着（崖檐下的洞口）→ 回 1 再看一眼；走不到 → 往下
           3 挖楼梯（不变）  4 找路走到远处的露天落脚处（不变）
           5 走回洞口（新，远的）：前面都不行，到访过的洞口在已加载区里 → 交给走到正常寻路过去一次；
               走不到 → 往下
           6 收场（不变；attempts 里多一条去洞口那一趟走没走到、为什么）
         离洞口远（超过 48 格）就是玩家平常的出法：近处见天、往上挖楼梯、找远处的露天，最后才回洞口
         没有洞口记录（长程挖矿挖下去的、掉进洞里的）照旧
         explore(target=surface) 不改：它是"朝某个方向找露天"，竖直上掘照旧
```

### 11.5 观众看到的

- 看得到的动作都是玩家会做的：走到洞口往里走，走一段停下转头看一圈，一路插火把，看见矿走过去，走进死胡同回头；出来时离洞口近就走回洞口，远了就近找见天的地方或挖楼梯上去。
- 黑地方的矿不报：屏幕上一片黑的地方角色也看不见，随行补光插下火把把洞壁照亮了，才看见洞壁上的矿。
- 不做的：直奔看不见的矿；挑岔路时用泛洪偷看哪边有矿、哪边是死胡同；穿墙直挖到矿。泛洪知道拐角后面通道的形状，只拿来判断连不连得通、走没走过，下一段只走到眼睛看得见的地方。
- 不干站：走一段看一眼约两秒，看的同时就在算下一段，算完接着走；泛洪分刻量，不让人站着等。
- 转头扫一圈就是感知层的环顾（`find` 扫描、闲时看也用它），全仓一份；实例配置关了闲时看（`idleLooking`）时站着看、不转头，量路看矿照旧。

### 11.6 组合的模型

M1（总流程）、M6（自卫、太暗插火把、吃饭插在两段之间）、M7（许可：走到挖路垫块、泛洪认不认往下跳）、M8（进度：新地方与新矿脉；结果与 attempts）、M9（矿脉、洞口、峡谷、岩浆湖入记忆，来源分到访与远望）、M10（走到与行程保证；回露天多一步走回洞口）、M12（洞口、峡谷、视线闸）。

本节自己特有的：洞口与峡谷的判断、钻洞的看一眼与挑下一段、走过的地方、回地面时走回洞口。

拒绝与提前失败的归类：看不见洞口是 NOT_FOUND（C：看不见就是没看见，说清看了多大范围）；不往水、岩浆、深坑走是 C（照样记下、告诉 LLM 那边有什么）；不许动土只认上下一格是 M7。没有新增 P、G、S。

### 11.7 能力说明的改动

- `target` 多一个写法 `cave`：钻进附近的矿洞顺着走、一路看矿。
- `max_distance`：钻洞默认 128（离 entrance 的直线距离），其余目标照旧默认 768；范围 64..2048 不变。
- `direction` / `angle_degrees`：钻洞时只用来挑哪个洞口（扇形里的），进了洞是打分时偏向那个方位，不是硬约束——洞往哪拐由洞定。
- `min_distance`：钻洞时用在挑洞口上，默认 0（有方向也是 0）。
- `interests`：钻洞时看见清单里的东西就走到跟前收场；其余目标照旧只记不停。
- 结果多 `entrance`、`branches`，`legs` 多一项走了多少格；`stop_reason` 多 `walk_limit`、`interest_seen`；`findings` 多一种矿脉（`ore_vein`，带块数）。

能力说明改成：

> 朝某个方向把外面的地形跑一遍：自由看看这一片有什么，或去找一种群系、一块能站的平地、回露天的地面；也能钻进附近的矿洞顺着走，一路看洞壁上露出来的矿。说好跑多大范围，到了范围边上就收工；路过的群系、岩浆湖、村庄线索、洞口、矿都会记下来，之后叫得出名字、去得了。地形走不动会自己换地方、换方向试，全试过才如实说卡住。走一段要挖土垫路时看许可，默认可以动天然方块。找具体的东西用 find（只看附近）；附近没有时先 explore 再 find。钻洞找矿给 interests（比如 `#c:ores/iron`），看见就停在跟前，接着 obtain 就挖得到；钻完回地面用 travel(here)：离洞口近会走回洞口，远了就近找见天的地方或挖楼梯上去。

采矿技能"什么时候去洞穴、峡谷"那一句改成能照着做的：看场景里有没有洞口、峡谷（f#）；有就 `explore(target=cave, interests=[要的矿])`，看见就停在跟前，再 `obtain`；看不见洞口再长程挖矿；回地面 `travel(here)`。

### 11.9 验收

**离线场景测试**（判断类用替身接口，任务用动作替身）：

1. 洞口：山坡上的洞（开口看得见、里面暗处够 24 格）报洞口，位置是开口能站的那格、真实高度；崖檐下浅凹不报；开口在墙后看不见不报；地上往下的竖井连着暗处报"往下"；6 格内两个开口合成一处。
2. 峡谷：长 20、深 12 的沟报峡谷，不再报落差；长 8 的坑照旧是落差；沟底沟壁都看不见不报。
3. 钻洞起步：在洞里就地开始；在地面走到最近的看得见的洞口；扇形外的洞口不挑；看不见洞口 NOT_FOUND，带范围与建议。
4. 挑下一段：只挑看得见的新地方；顺着方向优先；别的方向记成岔路；拐角后面是死胡同照样会去（候选只看眼前）；看不见新地方去最近的岔路；岔路也没了 frontiers_exhausted。
5. 泛洪：平走与上下一格连通；natural 往下 3 格算连通、none 不算；挨着岩浆一格、水里不算能走；泛洪边上的水、岩浆、深落差记成过不去的岔路。
6. 看矿：只记过视线闸的；拐角后面的矿（泛洪到了但看不见）不记、不影响挑哪边；同种相连算一条矿脉、带块数；暗处远的矿不算看见，插了火把（亮度够了）以后算；黑着也认得出离头 2 格内的矿。
7. 留意清单：看见留意的矿 → 走到够得着、看得见的地方收场 interest_seen；没给清单走到收场。
8. 收场：走满 256 格 walk_limit；再钻一次走过的不重走；不挑界外；换维度结束；一段都没走成 UNREACHABLE。
9. 走过的地方：每挪 2 格一个点；6 格内算走过，再钻一次不重走；换维度清空；4096 上限丢最早的。
10. 走回洞口：到访洞口在 48 格内，旁边几步不见天时先寻路去洞口（走到只收到洞口这一个目标，不是一串走过的格子），到了露天完成；超过 48 格先挖楼梯、找远处露天，都不行才去洞口；洞口走不到往下；没有洞口记录照旧；就地开始钻洞时脚下是开口格也记下洞口。
11. 先到安全处再停：钻洞的走行段跳在半空被叫停，落地站稳才停，落地不当成走到。

**实机验收**（实机暂停中，留验收）：

1. 山地 observe：山坡上的洞口报成 f# 洞口；travel(f#) 走到洞口站定。
2. 峡谷边 observe：报峡谷，不报成一片落差。
3. 洞口前 `explore(target=cave)`：走进去，走一段停下转头看一圈，一路插火把；看见的矿进结果与 world_memory，屏幕上黑着看不见的矿不报；全程没有干站超过几秒。
4. `explore(target=cave, interests=["#c:ores/iron"])`：停在铁矿跟前；接着 `obtain(minecraft:raw_iron)` 直接挖。
5. 钻到离洞口 30 格左右 `travel(here)`，`change_blocks=none`：寻路走回洞口。
6. 钻到离洞口 100 格以外 `travel(here)`，默认许可：不往回走，就近见天或挖楼梯上去。
7. 洞里有岩浆湖、地下水：不往那边走，branches 里写那边是什么挡着。
