# reserve — 预留身上攒着的东西

攒东西的时候用它：写下"身上这几样各留够几件"，角色自己做主时就不动它们。比如攒着 40 块木板盖房、23 块铁锭交任务、一组圆石搭桥，写下来之后，角色挖路时现做镐子、爬坑垫方块、挖楼梯填空洞、饿了顺手吃一口、背包满了腾地方，都绕开这些；预留着的工具也不会被自动拿出来挖。不占身体：`execute` 当场返回，不打断手上的事。

预留一直有效，跟着这个世界存下来，重启客户端也还在，不用每下一个目标重说一遍；不要了就用 `cancel` 撤。`observe(what="self")` 的 `reserved` 每次都列出现在预留着什么、身上各有几件。

## 下令的目标要用怎么办

你自己下令要用的，照用：`build` 图纸里的方块、`drop` / `deposit` / `eat` 写着的物品、做你要的东西非花不可的原料与燃料。先用身上不留的，不够才动预留的；动了几件就从预留里扣几件，结果的 `changes` 里那几条带 `from_reserved`（其中几件是预留的）。所以预留着 40 块木板去盖一栋用 30 块木板的房子，照放，预留剩下 10。

要命的时候不受它拦：血不到一半、饿到不能疾跑，身上只剩预留的吃的也照吃，先吃不留的。

## 参数

| 名字 | 必填 | 说明 |
| --- | :---: | --- |
| `operation` | | `set` 写下这几样各留够几件（默认，没提到的不变）/ `cancel` 这几样不再留，不给 `items` 就全部撤掉 |
| `items` | set 必填 | `[{"item": "minecraft:oak_planks", "at_least": 40}]`：`item` 是物品 ID 或 `#` 标签；`at_least` 是身上要留够的件数（1 起），不写就是这一样全都留着；同一样再写一次就换成新的件数。`cancel` 时只看 `item`，也可以直接写物品 ID 的列表 |

- 件数按身上的总数算（主背包、快捷栏与副手），不是"再多拿几件"，所以叫 `at_least` 不叫 `count`；写成 `count` 会被如实拒绝。
- 写 `#` 标签就是挂这个标签的几种加起来留够：`#minecraft:planks` 留 40，是各种木板加起来不少于 40。
- 身上还没有的也能先预留：攒铁时先写"铁锭留 23"，挖回来一块留一块。
- 物品 ID 写岔、标签下一件物品都没有、写了不认识的字段，一次报全（`INVALID_PARAMETER`），一条都不写进去。一次最多 32 样。不接受目标对象。

## 结果细节

| 字段 | 含义 |
| --- | --- |
| `reserved` | 改完以后的整份预留：每项 `item`、`at_least`（全都留着时没有这一项，`all` 为 `true`）、`carried`（身上现有几件，标签按合计） |
| `cancelled` | 这次撤掉的物品或标签 |

角色自己做主的花费被预留挡住没做时，那件事的结果里会说一句，例如"徒手挖：做镐要的木板预留着（留 40，身上 22）"。
