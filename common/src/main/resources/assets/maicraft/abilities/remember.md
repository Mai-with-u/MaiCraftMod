# remember — 记住或忘掉一个地点、标注箱式加工站，或圈一块玩家地盘

让角色按名字记住一个位置（"这是家""那是矿洞口"），把以某处为中心的一片圈成玩家地盘（"这一片是我的基地，别动"），把一进一出两只容器标成通用箱式加工站（投料进料箱、取出料箱，`obtain` 烧炼时优先走它），或者忘掉一个记过的名字。只改角色的世界记忆，不移动角色、不读地形、不核实那里能不能站人——这些交给真正去那里的能力。执行是当场完成的：`execute` 直接返回结果，不成为主任务，也不打断手上正在做的事；放进 `sequence` 时，按顺序轮到它才记。

## 参数

| 名字 | 必填 | 说明 |
| --- | :---: | --- |
| `name` | | `remember`、`region`、`station`、`forget` 必填：地点、地盘或加工站的名字，首尾空白去掉后原样比较，不改大小写；`forget_area` 不用给 |
| `operation` | | `remember` 记住地点（默认，同名覆盖）/ `region` 以目标为中心圈一块玩家地盘 / `station` 标注箱式加工站（投料容器 + 取货容器） / `forget` 忘掉同名的地点、地盘与加工站 / `forget_area` 清掉目标周围一片失效记忆 |
| `radius` | | 用于 `region`（地盘半径，默认 8，1–64）或 `forget_area`（清理半径，必填，1–512） |
| `via` | | 用于 `station`：加工站用途途径，默认 `smelt`（烧炼） |
| `input` | | 用于 `station`（必填）：投料容器位置，写法支持观察编号 `b#`、坐标 `[x,y,z]` 或记住的地标名 |
| `output` | | 用于 `station`（必填）：取货容器位置，写法同 `input`，允许与 `input` 为同一容器 |
| `exclude` | | 用于 `station`（可选）：不交给这个加工站处理的物品 ID 或 `#标签` 列表（例如 `["#maicraft:foods/edible"]` 让食物仍走熔炉或烟熏炉） |

## 目标对象（用于记住地点和圈地盘，省略就是 `here`）

| kind | 记下的位置（圈地盘时是中心） |
| --- | --- |
| `here` | 角色此刻脚下那一格 |
| `seen` | 观察编号指向的位置；实体是最后一次看到它的位置 |
| `landmark` | 另一个记住的地点的位置，用来给同一个地方再起一个名字，或以它为中心圈地盘；没记过这个名字时，认附近看得见、写着它的那块告示牌，记下牌子那一格 |
| `position` | 给的坐标；**必须给 `y`**——记住的地点会被出行当作确认过的目的地，不存猜的高度；不知道高度就先走过去，再用 `here` 记 |

`player`、`direction`、`previous` 不接受：玩家在场景里有观察编号，用 `seen` 指它。

## 圈地盘

- 地盘是一块明确的范围：中心加半径，按直线距离算。圈下立刻生效，之后所有任务都把里面的方块当受保护——拿东西、挖矿、施工、走路都不拆，里面的箱子不当成能取用的存储。不用再在任务许可里写它。
- 只想在某一次任务里避开一个地方，用任务许可的 `protected_landmarks` 写地点名；要长期护住主人的基地，圈成地盘。
- 地点和地盘是两本账：同一个名字可以既是地点又是地盘。`observe(what=world_memory)` 的 `regions` 列出每块地盘的名字、中心、半径。
- 里面的生物照旧按有名字、驯服、拴绳、围栏里判断受不受保护，圈地盘不改这一条。

## 箱式加工站（`operation=station`）

- 只要一条自动加工线有“投料箱”和“出料箱”（允许两口是同一只箱子），就可以用 `operation=station` 标成通用箱式加工站，不限原版或模组实现。
- 标成 `via="smelt"`（默认）后，`obtain` 烧炼目标物时若目标物与原料都没命中 `exclude`，会自动优先走这个加工站：免燃料、不搓炉子，先看有没有同目标物正在加工中，少量投料后在出料箱短等取出，大批量则登记在跑账本并自动挂计时，到点再回来取。
- 命中的物品或原料（如 `exclude=["#maicraft:foods/edible"]` 排除食物）不会交给本站，自然回落到熔炉或烟熏炉。
- `observe(what="places")` 与 `observe(what="world_memory")`（含 `sections=["stations"]`）都会列出所有已标注的箱式加工站。

## 边界与注意

- 记下的位置都带维度：目标对象没写维度的，按角色此刻所在的维度记。
- 同名覆盖：结果细节 `previous_position`（圈地盘还有 `previous_radius`，标注加工站有 `previous_station`）写出原来记成什么；没变就直接完成，说"本来就这样记着"。
- 忘掉：同名的地点、地盘与加工站一并忘，结果写出忘掉的是哪几样；三样都没记过就失败（`NOT_FOUND`），问题里附上记得的全部地点名、地盘名与加工站名，不会把写错的名字当成已经忘掉。
- 结果细节：`name`、`operation`；记住地点时有 `position`，圈地盘时 `position` 是中心、`radius` 是半径，标注加工站时有 `station`；改记时有 `previous_position`（与 `previous_radius`）或 `previous_station`；忘掉时 `previous_position` 是忘掉的地点，`forgotten_region` 是忘掉的地盘，`forgotten_station` 是忘掉的加工站。
- 按范围清理（`operation=forget_area`）：服主重新生成地形或整片搬迁后，清掉中心 `radius` 格内（同一维度）按名字记的地点、自动记下的容器、工作站、产地线索；圈的地盘、标注的加工站、建筑与机器档案、还没收回的临时方块不动。结果细节 `forgotten` 逐个列出被清掉的命名地点（名字和原坐标，误清可照着记回）及各类记忆清掉的条数。
