# chat — 向游戏聊天发一句话

让角色对着全体玩家说一句话，像玩家在聊天栏打字发送一样：角色会真的打开聊天框，把话一个字一个字打出来（每个完整可见字符约 0.1 秒，组合表情按一个字），整句打完停一下再提交。所以长句子要打好几秒，急话拆短了说；打字途中生存需求会先插进来自救（公屏说话时只有换气、掉进岩浆这类立刻要处理的才插），聊天框暂时关掉，回来接着把剩下的字打完，没打完的话不会发出去半句。聊天框被别的界面占着时会等它让出来（最多约 3 秒），等不到以问题种类 `REFUSED_BY_GAME` 收场、说明框被占。

公屏说一句话是**插一下**：不替换手上的目标，平时空得出手就压在它上面逐字打完、回车，手上的事从原地接着做（结果细节 `typed=true`）；身体正忙腾不出来时（自卫、换气、撤离、开着车或悬在半空停不下），等半秒还腾不出身子就不逐字打，整句直接发出去（`status=done`，`typed=false`），不会被反射挡掉。人按 F8 在操作角色、或前面已经排满 4 件插一下的事时，以 `WRONG_TIME` 收场并说清是哪一种。发游戏命令（`/` 开头）和对一只生物说话（给 `target`）仍会替换手上的目标。

发出后以聊天栏出现自己那条（本地回显）为完成依据；回显读不到时结果会说明"已提交但没能确认"，并在 `unconfirmed` 里记一条——这时不要盲目重发。

## 参数

| 名字 | 必填 | 说明 |
| --- | :---: | --- |
| `message` | ✅ | 要发到游戏聊天的话，全体玩家可见；以 `/` 开头的按游戏命令发：普通玩家命令照发，管理员命令角色不执行。给了 `target` 就是对那只生物说 |
| `max_seconds` | | 对生物说话时，说完以后最多站着等回话几秒：默认 30，最多 90，0 表示确认它听到了就走 |

`target` 可以给一只生物的观察编号 `e#`，就是对它说：不进公屏，`/` 开头的也照原话说给它听。

## 对一只生物说话

有的模组里生物能听人说话（车万女仆的女仆）：角色走到它跟前、看着它、打开它的对话框，逐字打字、回车，再站着等它回话。逐字打字与公屏说话同一个节奏；打字途中被生存需求打断，回来重新开框从头打。它还在想上一句时先等它想完再说，等满 `max_seconds` 还在想，这句就不说（`WRONG_TIME`）。

结果细节：`message` 说了哪句；`to` 对谁说的（观察编号与名字）；`delivered` 它确实听到了；`reply` 它的回话（没等到不给）；`reply_pending` 没等到回话，之后的回话照常进 `events(topic=chat)`，不用重说；`notices` 这段时间聊天栏收到的其他系统消息原话；`persona_generated` 它这次只生成了一份人设、没回答，要再说一遍。它用这句话改了自己的状态（坐下、跟上、换工作）按 `ENTITY_AFFECTED` 变化列出；回话本身不当成它做了什么的证据。说出去了却没看到它有反应，记进 `unconfirmed`，不要重说。

问题种类：`NOT_POSSIBLE_HERE` 它不会听人说话、不是你的；`UNSUPPORTED` 它所属的模组装了，联动没登记（看启动日志）；`INVALID_PARAMETER` 话太长（上限由它的对话框定，改短了再说，不要拆成两次）；`REFUSED_BY_GAME` 它那边回了提示、没有回话（原话附上）；`TARGET_GONE` 它走了、没了；`WRONG_TIME` 它一直在想上一句。

## 边界与注意

- 游戏命令像生存玩家一样用：`/msg`、`/home`、`/help`、`/spawn` 这类普通玩家命令照发，成没成看结果里的 `feedback`（命令反馈行）；`/tp`、`/give`、`/gamemode`、`/time` 这类管理员命令角色不执行，会被直接拒绝（问题种类 `REFUSED_BY_GAME`）——要去哪、要东西、改世界靠能力去做。`/maicraft` 与 `/mai`（服主管谁能当角色）永远留给人。
- 读别人的聊天、听别人说话不属于本能力，那归观察侧。
- 结果细节 `message` 是实际交出去的那句话。
