对一个方块或实体用一下手上的东西，就像玩家按一下右键：开门、按按钮、拉拉杆、打开箱子看看里面有什么、骑上马或船、剪羊毛、挤奶、用桶舀水或倒水、用打火石点火、用锄头耕地、用刷子刷可疑的沙子或沙砾、在告示牌上写字。不给 item 就空着手用；身上没有 item 会先去拿一件。target 指定对哪个东西用；只给 block 或 entity 时，用附近最近的那一个。count 是做几次。打开的界面会在列出内容后关上。刷子要对着一格用（可疑的沙子、沙砾），会一直按住直到那一格变回普通方块，刷出来的东西捡回背包。锄地、铲土径时目标上面长着短草、蕨、花这类一下就能打掉的野生草木，会先打掉它再锄（和挖方块一样要 `change_blocks` 到 `natural`，别人种的不动）。放方块用 build，挖和砍用 gather，打怪用 fight，吃东西用 eat，存东西用 deposit，从箱子里拿东西用 obtain。只给 item 不给目标就是对着手上用（喝药水、扔喷溅药水、吹山羊角）；几瓶药水长得一样时给 `potion`（药水种类，例如 `minecraft:fire_resistance`）挑写着这种药水的那一瓶，不给 item 当普通药水瓶，不给 `potion` 就拿身上第一瓶。指定 `face` 时只点方块朝这一面的表面：用扳手转机械动力的机器时，点哪一面决定绕哪根轴转（点朝向那一面只切换转轴，点侧面才转朝向）。拿水桶、岩浆桶、打火石时点名 `face`，就倒在、点在这一面外面那一格（对草地的 up 面倒水，水就落在草地上面）；不点名按朝向自己的那一面。给 `keep_trying`（秒）时，点下去没反应就接着点，每一下只等几刻，最多这么多秒，点中就停：传送带上跑着的东西要这样连着点才抓得到；不给就点一下没反应就停，不重复点。给 `sneak=true` 时按住潜行再右键：潜行右键马、驴打开它的物品栏，潜行右键女仆让她坐下、喂她金苹果；不给就不潜行，写告示牌时不能潜行。

## 结果怎么读

- `applied_times`：确认生效了几次。某一次没有效果就停下，做成了几次就写几次。
- `used_on`：这一下对着什么用的：`air`（没给 `target` 或只给 `target=here` 且不带 `face`、也没给 `block`/`entity`，对着空气用手上的东西）、`block`、`entity`。魂符、刷怪蛋、骨粉这类东西必须对着地面方块或生物（`e#`）用：放在脚下地面上可以直接传 `target=here` 并配 `face=up`，对指定方块用给那一格（`b#` 或坐标，放顶面配 `face=up`）；对着空气用不会生效。
- `opened`：打开过的界面，里面有什么（按物品合并）。看完就关上了。点开的是方块容器时，另带 `whose`（容器是谁的：`natural_loot` / `self` / `player` / `no_record` / `unknown`）、`last_modified_by`（仅 `whose=player` 时有）与 `opened_by_self`（这一次点开之前世界记忆里有没有打开过它的记录）。
- `sign_text`：告示牌上实际写下的字，逐行。超宽的行游戏会截掉，没写上去的部分在 `remaining` 里。
- `riding`：骑上的东西。目标本来就是正骑着的坐骑时，直接完成。
- `game_messages`：生效的那几下前后，聊天栏收到的服务端系统消息原话（模组、插件的提示，也可能是别人进出服务器）。不按文字猜和这一下有没有关系，要不要当回事你来判断。
- `unrecognized_processor`：对着未专门联动的模组加工容器（如农夫乐事厨锅、煎锅、砧板等带方块实体的台子）右键把物品放了进去、或点开了不认识的方块界面时为 `true`，一句话结论会明说"放进去了，不确认会不会做出东西"或说明手上的东西没放进去，不能把交互生效当成产物已经做好。
- `unconfirmed`：点下去了却没能确认有没有生效的那一下。不会再点第二次去赌，结果是部分完成。
- 空桶点到流动的水时，改舀 8 格内最近的同种水源。

## 问题种类

- `TARGET_GONE`：观察编号对应的东西不在了，或那一格的方块变了；重新 `observe` 拿新的编号。
- `NOT_FOUND`：查过的范围内没有目标（只查已加载的区域）；换个地方，或用 `find`。
- `DANGER`：下界、末地的床和主世界、末地的重生锚右键会爆炸，不会去点。
- `NEED_ITEM`：身上没有要用的东西，也没办法拿到一件。
- `NEED_APPROVAL`：这样用会改动它（倒流体、点火、耕地、剪毛、挤奶、喂食、染色这类），而目标受保护（在圈起来的地盘里或额外保护地标旁的方块，有名字、被别人驯服、拴着、圈着的生物；你自己驯服的不算）。开门、按按钮、拉拉杆、打开箱子看看、空手骑乘不受这条限制。确实要用，先 `observe` 再用观察编号点名它；按类型找时附近只有受保护的也会这样说。
- `REFUSED_BY_GAME`：游戏拒绝了这次交互（上锁、领地保护、上过蜡的告示牌、模组在聊天栏里说的"名额满了""这不是你的女仆"），附上游戏给的原话；没生效而聊天栏里收到了服务端的话，也按这一种交回。
- `NOT_POSSIBLE_HERE`：这样用没有效果；换个目标或换个用法。
- `UNREACHABLE`：试过的站位都够不着或看不见目标。
- `UNSUPPORTED`：弓、弩、三叉戟、盾牌、望远镜、钓竿这类要凭时机松手的物品不接，指向对应的能力；掉落物、经验球、射出去的箭准星选不中，捡东西用 gather。
