# maid_configure 改女仆的设置

车万女仆模组里的女仆是一种可驯服生物，不是角色。这个能力走到自己的女仆跟前，打开她的界面，照真人点按钮的样子一项项改她的设置。装了车万女仆才可用。

## 参数

| 名字 | 必填 | 说明 |
| --- | :---: | --- |
| `target` | ✅ | 她的观察编号 `e#` |
| `settings` | ✅ | 要改成什么：JSON 对象，键是下表的设置项，值一律写字符串；按给的顺序改 |

| 键 | 取值 | 说明 |
| --- | --- | --- |
| `skin` | 皮肤 ID，例如 `geckolib:winefox` | 只能挑本机模型表里有的 |
| `work` | 工作 ID，可省 `touhou_little_maid:`，例如 `farm` | 只能挑她工作列表里的 |
| `work_shift` | `day` / `night` / `all` | 白班、夜班、全天 |
| `stay` | `with_you` 跟着你 / `in_area` 待在活动范围里 | 设过日程点就围着日程点，没设过以她此刻的位置为圆心 |
| `pickup` | `true` / `false` | 捡不捡地上的东西 |
| `mainhand`、`offhand`、`head`、`chest`、`legs`、`feet` | 物品 ID 或 `#标签`；空字符串拿回 | 从角色背包点进她那一格，她原来拿的换回角色背包；空字符串把那一格的东西拿回角色背包 |

坐下不在这里，用 `use(sneak=true)` 对她空手右键。

## 怎样算完成

- 每项都要看到她同步下来的那个值变成目标才改下一项，每项最多等 2 秒；全部改完关上界面。
- 已经是目标值的项不动，记进 `skipped`；全部都已是目标值时不开界面。
- 值不认识：`INVALID_PARAMETER`，一项都不改；皮肤附最相近的三个 ID，工作附全部能切的工作。
- 键她不认识：`INVALID_PARAMETER`，附她认的全部键。
- 装备项角色背包里没有那件：`NEED_ITEM`，先 `obtain` 拿到再放。
- 游戏不让：`REFUSED_BY_GAME`，停在那一项。常见的有：她在睡觉（界面打不开，等她醒了再改）、不是你的女仆（界面只给主人开）、服务器关了换皮肤（附聊天栏原话）、开驻守时日程点离她超过 32 格或不在同一维度（车万女仆弹出确认屏，角色关掉它）、工作按钮是灰的（附界面写的条件）、盔甲格不收这件。
- 改了却等满没看到变化：记进 `unconfirmed` 并停下，后面的项不改；先 `observe` 看她的 `maid` 再决定要不要重来。
- 不是女仆：`NOT_POSSIBLE_HERE`；车万女仆装了但联动没登记（版本不在验证范围）：`UNSUPPORTED`，看启动日志。

## 结果怎么读

- `changes`：改成的每一项按生物受影响列一条，写明从什么改成什么。
- `details.applied`：改成的项，每项 `key`、`from`、`to`。
- `details.skipped`：本来就是目标值、没动的项。
- `details.work_hint`：切了工作时，界面上这份工作写的条件（例如"主手需要锄：不满足"）。切工作不看她手上有没有合适的工具，缺了她只会站着不干，满不满足自己看。
- `details.shift_now`：她此刻在干什么（`work` 工作中、`rest` 休息、`sleep` 睡觉）；不在工作时段切了工作，她要等班次开始才动。
