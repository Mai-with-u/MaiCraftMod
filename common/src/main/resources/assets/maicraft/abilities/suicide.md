# suicide 寻死

开着死亡不掉落（keepInventory）时主动死一次，重生回出生点或床边。死了再重生、把脱下的护甲穿回才算完成。

## 用途

- 死亡不掉落开着时，寻死是正常手段：一次回到重生点（床边、重生锚，没有就是世界出生点，看 `observe(self)` 的 `respawn`），血和饱食度都是满的。
- 位置和手头进度不要紧时用。不要紧指：不在施工半路，附近没有要捡的东西，不是在远处干到一半的活。这时比硬撑着找吃的、慢慢回血、费劲脱困、从远处走回家都省事。
- 死亡不掉落关着时不用：死了东西全掉在原地。正常回家用 `travel`。

## 怎样算完成

- 服务器给了 `/suicide`，或角色能用 `/kill`（命令树里有就是能用），先发命令：`/kill @s` 直接发，`/suicide` 先把手上的不死图腾收起来再发，都不脱甲（死亡不掉落开着护甲本来不掉）。只发一次，5 秒没死就当不管用，服务器回的话记进 `attempts`，再照下面脱甲找别的死法。
- 不用命令时先把身上的护甲逐件脱进背包，手上的不死图腾收进背包（不然死不成）；背包满、绑定诅咒脱不下的就带着死，`details.armor_still_worn` 写明。
- 然后挑一种死法走过去：不给 `via` 时按死得快慢挑——附近的岩浆、摔得死的落差（按此刻血量算，落进虚空也算）先；身上有打火石或火焰弹就原地点火；再是仙人掌、会打人的敌对生物；岩浆桶最后（倒出来的岩浆收不回去）。同一档里挑最近的。给了 `via` 只用那一种，用完了不换别的；`via=command` 发了 5 秒没死按卡住结束，`problem` 带服务器回的话。
- 身上有抗火效果时不用岩浆和火；有缓降时不跳崖。
- 接触一处后 20 秒没再掉血、摔下去没死、走不到，就换下一处；放弃的原因记在 `attempts`。
- 点火、倒岩浆只在身边 8 格内挑一格：脚下结实，周围（火 1 格、岩浆普通维度 6 格、下界 10 格）没有会被点着的方块、没有受保护的方块。右键出去没出效果就不再用这种死法，不换格反复试。点火、倒岩浆是寻死的手段，`permissions.change_blocks` 不管它（默认 none 也照做），受保护的格照旧不放；结果的 `changes` 写在哪放了火或岩浆。
- 死了以后：发 `character_died`，挂死亡恢复问题，没人回答 2 秒后自动重生；重生后把脱下的护甲按原件（附魔、耐久一样的那一件）穿回原部位，原部位已经有别的就不换。不死图腾不放回手上。
- 从脱甲到死，角色不吃饭、不睡觉、不自卫、不防摔（`survival_needs` 不用写，寻死自己会关）；重生后、穿回护甲时、目标暂停时恢复。
- 没死成（附近没有死法、超过 `max_seconds`）也先把护甲穿回再结束；暂停、取消时同样先穿回再停，恢复后重新脱。

## 死亡不掉落

- 单人世界、开局域网的主机：直接读游戏规则，关着就不做，不看 `keep_inventory_confirmed`。
- 连别人的服务器读不到这条规则：给 `keep_inventory_confirmed=true` 就做；不给会问一句"这个服务器开着吗"，答 `yes` 接着做，答 `no` 不做。
- 创造、旁观模式死不了，极限模式死了不能重生，都不做。

## 结果怎么读

- `changes`：脱下、穿回的每件护甲，收起的图腾，点的火、倒的岩浆，用掉的火焰弹、倒空的岩浆桶。
- `unconfirmed`：右键出去没等到确认的点火、倒岩浆。
- `details.way`：最后用的死法（`command` / `lava` / `fall` / `cactus` / `hostile_mob` / `fire` / `lava_bucket`）。
- `details.command`：发过的寻死命令（`/suicide` 或 `/kill @s`），没发没有这一项。
- `details.keep_inventory_known_by`：怎么知道开着死亡不掉落的——`game_rule` 读到游戏规则，`caller_confirmed` 你确认的。
- `details.armor_still_worn`、`details.totems_still_held`：没脱下、没收起的，带原因。
- `details.armor_not_restored`：脱下了没穿回的，带原因（原件找不到、原部位有别的、被新目标替换来不及穿）。
- 没死成时 `problem.message` 按死法摊开说一次：试过的说放弃了几处、为什么；没试的说为什么用不上（没带打火石、附近没找到……）。
