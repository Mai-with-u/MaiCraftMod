# gomoku_play 和女仆下五子棋

和坐在棋盘对面的女仆下车万女仆的五子棋：角色执黑先手，空手对准那一路右键落子，再站着等她应手；或者点棋盘角上的棋盒重开一局。装了车万女仆才可用。

## 参数

| 名字 | 必填 | 说明 |
| --- | :---: | --- |
| `target` | ✅ | 棋盘的观察编号 `b#`（`observe` 的 `mod_things` 里 `gomoku_board` 那一项） |
| `move` | 落子时 ✅ | 这一手下在哪：列 A–O 加行 1–15，例如 `H8` 是天元 |
| `operation` | | `move` 落一子（默认）；`reset` 重开一局 |
| `max_seconds` | | 落下以后最多站着等她应手几秒：默认 15，最多 30；轮到她时先等她下完也按这个 |

记谱站在你这一侧看：你坐在她座位的对面，面朝她，列 A–O 从左到右，行 1–15 离你最近的是 1。`observe(detail)` 看棋盘的 `board`：15 行，`X` 是你、`O` 是她、`.` 是空，第一行是离你最远的第 15 路。

## 怎样算完成

- 落子：那一路变成你的子才算落下，然后等她应手，棋盘上多了她的一子就完成。等满没应不算失败，`details.reply_pending` 为 true，过一会儿 `observe` 再看。
- 这一手分出胜负时不再等，结论写谁赢了。
- 写法不对、那一路已经有子：`INVALID_PARAMETER`，不点。
- 这一局已经结束：`WRONG_TIME`，先 `operation=reset` 重开。
- 轮到她下：先等她下完再落子；等满还没下就这一手不落，`WRONG_TIME`。她起身离开了座位时，下一手前要她重新坐回来。
- 游戏不让：`REFUSED_BY_GAME`，附聊天栏原话。常见的有座位上没有女仆、她不是你的女仆。
- 右键了却没看到棋盘变化、也没有回应：记进 `unconfirmed`，先 `observe` 看棋盘再决定要不要重下。
- 重开：棋盘清空才算做成；本来就是空棋盘时直接完成，不点。

## 结果怎么读

- `changes`：落了一子、重开了一局，按方块变化列出。
- `details.your_move`、`details.maid_move`：你下在哪、她应在哪。
- `details.board`、`details.turn`（`you` / `maid` / `over`）、`details.winner`（`you` / `maid` / `draw`）：此刻的棋盘和这一局的状态。
- 赢了以后她的好感涨多少、段位升没升由车万女仆自己结算，看她的 `maid` 字段与聊天栏。

## 怎么让她坐上棋盘

休息时段她自己会去附近的空棋盘边坐下；工作时段要先用 `maid_configure` 把她的工作切成 `board_games`。
