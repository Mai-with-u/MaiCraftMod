# 矿物生成高度：去哪一层找矿

主世界和下界的矿按高度分布，每种矿都有自己最多的那一层（1.18 以后的生成规则，下界的数按 1.21.1）。找矿先到对的高度，比在错的高度挖一整天有用。

## 规则

| 矿 | 生成范围与最多的地方 |
| --- | --- |
| 煤 | Y 0 以上都有，Y≈95 一带和高山上最多 |
| 铜 | Y -16 到 112，Y≈48 最多；溶洞里更多 |
| 铁 | Y≈16 一带最多；高山 Y≈232 附近还有一大批；深层零星也有 |
| 金 | Y -64 到 32，Y≈-16 最多；恶地群系地表附近额外多 |
| 青金石 | Y -64 到 64，Y≈0 最多 |
| 红石 | Y 15 以下，越往下越多 |
| 钻石 | Y 16 以下，越往下越多，Y≈-59 最多 |
| 绿宝石 | 只在山地群系，越高越多 |

- Y 0 以下是深板岩层：矿变成深层版本（例如 minecraft:deepslate_iron_ore），挖得更慢，掉的东西一样。
- 钻石矿贴着空气的那一面多半不生成，所以洞穴壁上少见，要往实心岩层里挖。
- 铁矿、金矿、铜矿挖出来是粗矿（minecraft:raw_iron 这类），锭要烧出来；煤、钻石、青金石、红石、绿宝石直接掉成品。

下界：

| 矿 | 生成范围与最多的地方 |
| --- | --- |
| 远古残骸 | Y 8 到 119；大团只在 Y 8–24、Y≈16 最多，站在 Y15 横挖（通道占 15、16 两层）最好 |
| 下界金矿 | Y 10 到 117，各层一样多；玄武岩三角洲里更多 |
| 下界石英 | Y 10 到 117，各层一样多；玄武岩三角洲里更多 |

- 远古残骸贴着空气的那一格一格都不生成：洞穴壁、岩浆湖边永远看不到，只能自己挖通道让它露出来；要钻石镐以上才挖得下。
- 下界海平面是 32：Y31 及以下挖穿的洞都灌满岩浆。岩浆块在 Y 27–36 成团，站上去不潜行会烫脚。
- 挖下界金矿会惹恼 16 格内的猪灵，不管它看没看见你。

## 这个规则会怎么坑你

- 站在地表要深层的矿（钻石、红石），附近根本没有；先下到那一层附近再找。
- 在高处找钻石、在深处找绿宝石，挖再久也白挖。
- 在洞壁上找远古残骸：它从不贴着空气生成，看见的洞壁上一块都不会有。

## 在本 Mod 里

`maicraft:obtain` 的采掘先挖角色附近**看得见**的矿，埋在石头里的不算（不透视）。附近看不见时：圆石从脚下往下挖楼梯去找；表里这几种原版矿按"最多"那一栏长程挖矿——在那一层之上就挖台阶下去，到了那一层（或已经在那层以下、还在生成范围里）横着挖通道，看见了就挖（铁 16、金 -16、钻石 -59、红石 -58、青金石 0、铜 48、煤 95；下界远古残骸 15，下界金矿、石英各层一样多就在这一层横挖）。要的矿只在别的维度生成时，它会说清在哪个维度，先用 `maicraft:travel` 过去再要。下一级脚下是岩浆块、挨着岩浆就拐开。绿宝石和模组矿不长程挖，先去山地、洞穴、峡谷里找露出来的再要；往下走可以用 `maicraft:travel` 给带高度的坐标。细节看各自的能力说明。

## 边界

表里是原版生成规则的大致分布，整合包或模组可能改动；实际有没有以现场为准。
