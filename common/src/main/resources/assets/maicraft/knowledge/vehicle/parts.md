# 载具部件：飞艇和车怎么搭

机械动力航空学一套（Simulated、Create Aeronautics、Offroad，跑在 Sable 物理上）里，载具就是一堆用胶粘好的方块，拉一下物理组装器变成一个会动的物理结构。这篇只讲每样部件干什么、怎么摆、哪里容易错；从搭到开的先后看技能 `skill://create/create-vehicles/SKILL.md`。

方块名用游戏里的中文，括号里是 ID。每样部件的思索演示挂在它的物品资料页上（`lookup(topic=knowledge, id=物品 ID)`），配方用 `lookup(topic=recipe, id=物品 ID)` 查；这里不重复。

## 每辆都要的

- **物理组装器**（`simulated:physics_assembler`）：放在船身的一块方块上。放在顶面上就从它下面那块开始组装，贴墙放从它背后那块，贴天花板从上面那块。组装后它跟着船走，以后拆回也拉它。
- **强力胶**（`create:super_glue`）：只有同一块胶框住、又互相挨着的方块才连成一体，斜对角挨着的也算。一块胶两个对角相距不到 25 格，大船分几块框，相邻两块至少叠一层。框进去的地面、脚手架会被一起带走：船底下垫的东西放在胶框外面。风帆和风帆框架自己会粘在旁边的方块上，不用胶。
- **座位**（`create:white_seat` 这类各色座位）：离无线红石打字机 3.5 格内的座位是驾驶座。没有座位或没有控制件的物理结构只算"会动的结构"，不算载具，开不了。
- **无线红石打字机**（`simulated:linked_typewriter`）：控制件。每个键绑一组频率（两格物品，顺序也算），按住就往这组频率发信号。放在驾驶座够得着的地方。
- **收端**：机械动力的无线红石信号终端（`create:redstone_link`）切成接收，两个频率格放和那个键一样的两样物品。它给前后左右上下的方块都输出红石，贴着的那块还会被充能，再传给那块旁边的红石元件。
- **收端紧贴着它要控制的部件放**：Mod 按"收端旁边接着什么"推这个键的作用（燃烧室、蒸汽喷口是升力；扭力弹簧、定向齿轮换向器、车轮悬架是转向；螺旋桨轴承、模拟传动器是动力）。隔着红石线、齿轮、离合器，或一个收端同时挨着几种部件，就推不出；推错了也不要紧（下面动力键开的是换向器，会先被推成转向），试按会按船实际怎么动改过来。别让一个收端顺带挨着别的部件，不然一个键会同时开两样东西。
- **整艘的外框别太大**：长×宽×高超过 32768 格（比如 32×32×32）Mod 就读不全，种类说不清，开不了。
- **频率别撞**：同一组频率在整个世界里是通的。每辆载具用自己的一套组合（比如第一格都放这辆独有的一种羊毛，第二格按键区分），别和门、电梯、别的载具重复。

## 船上的转动从哪来

- **便携式引擎**（各色 `simulated:*_portable_engine`）：手持燃料右键加进去（空手右键会把里面的燃料取回来），烧着就一直出 32 转（喂烈焰蛋糕超级加热时翻倍），不受红石控制。开关靠下游的换向器。
- **定向齿轮换向器**（`simulated:directional_gearshift`）：两边都没信号时不传动；颜色深的一面（朝向那面，直输端）有信号照原方向传，对面（反转端）有信号反着传，两边都有信号又停。所以它就是"按住才转、松开就停"的开关：动力键的收端贴直输端，倒车键贴反转端。
- 机械动力的离合器是反的（有信号断开）；模拟传动器（`simulated:analog_transmission`）有信号就改传动比，满信号直接断开。两样都不适合当"按住就走"的键。
- 动力够不够看 `machine_inspect` 那张应力网的读数；过载整网停转，桨和车轮都不动。

## 飞艇：升力

- **气球**：用气球蒙皮（各色 `aeronautics:*_envelope`）或任意羊毛围出顶和四周，缺一块就漏。热空气从上往下充；里面的方块占容积；传动杆要穿过气球就用蒙皮传动杆箱包住才不漏。
- **热空气燃烧室**（`aeronautics:adjustable_burner`，能力说明里叫可调燃烧器）：放在气球下面或里面，正上方第一块挡住它的方块必须是气球顶的蒙皮或羊毛，中间有别的方块就找不到气球。不烧燃料，有红石信号才出热空气，信号越强出得越多；设置框调最大出气量。升力上限看气球多大，几台燃烧室可以供同一个气球。升力键的收端贴在燃烧室旁边。
- **蒸汽喷口**（`aeronautics:steam_vent`）：往上方气球充蒸汽，要像蒸汽机一样有热源、水和锅炉，比燃烧室麻烦。
- **浮空水晶**（`aeronautics:levitite`）：够多就能让船浮着，但光靠它升不了高，还要别的向上的力；低速时还会明显拖慢船。
- **越高越飘不动**：气压随高度降低，气球升力和螺旋桨推力都变弱，船会停在升力等于重量的那个高度。巡航高度定得太高会升不上去。
- 只靠朝上的螺旋桨（像直升机那样）、没有燃烧室、蒸汽喷口、气球蒙皮或浮空水晶的，会被认成固定翼，现在开不了。

## 飞艇：推进

- **螺旋桨轴承**（`aeronautics:propeller_bearing`）：正面那块方块连同上面的风帆（至少 2 块像风帆的方块）就是桨，风帆越多推力越大。从背面接进来的轴转起来时它自己把桨装起来，停转后桨留着不拆；转速为 0 时右键它不会装。转向反过来推力就反，扳手或设置框里的"推力方向"也能反。
- 推力朝哪边都行：第一次试按动力键，船往哪边走，哪边就是车头。
- 船已经在飞时桨推不了那么猛（空气已经在相对它流动），推力会随速度下降。
- 木制、安山、智能螺旋桨是转起来自己就出推力的小桨方块；它们接的键 Mod 推不出作用，要试按。
- **陀螺仪螺旋桨轴承**（`aeronautics:gyroscopic_propeller_bearing`）：会尽量让桨保持竖直朝上，适合托住上重下轻的船；给红石信号会把倾斜归零。

## 飞艇：转向

两种做法，挑一种：

- **左右两个桨分开开**：左右各一个螺旋桨轴承，各接一个定向齿轮换向器。两个换向器的直输端都贴前进键的收端；左边那个的反转端贴左转键的收端，右边那个的反转端贴右转键的收端。只按左转键，左桨倒推，船原地往左转；和前进键一起按，左桨停、右桨推，边走边往左拐。慢速时也转得动，最省事。
- **舵**：动力 → 定向齿轮换向器（左右两个键的收端分别贴直输端和反转端）→ 扭力弹簧（`simulated:torsion_spring`，朝向那面出转动）→ 机械动力的动力轴承（`create:mechanical_bearing`）→ 轴承正面粘的帆面。弹簧在设定的角度范围内转，输入一停就回正；弹簧本身被红石充能时不回正，别让收端的信号串到它。动力轴承要用设置框改成永远不放回方块，不然回正停转时帆面会掉回成方块。气动舵在慢速时作用很弱，飞艇低速转弯更靠左右两个桨。
- 对称风帆（各色 `simulated:*_symmetric_sail`）只产生阻力，适合做稳定面和舵；普通风帆在结构移动时会产生升力。

## 车

- **车轮悬架**（`offroad:wheel_mount`）朝外放在车身两侧，轮子装在它朝外那一面：手持车轮（`offroad:tire`，另有小型、大型、巨型）右键它那一面。动力从它背面接进来，转起来车轮才使劲。
- 正上方给红石是刹车（信号越强刹得越死）；两侧（沿车身前后挨着它的两格）给红石是打方向，最多约 30°。前轮前后两格各放一个收端，左转键、右转键各一组频率；后轮上方放一个就是刹车键。
- 两个前轮朝外的方向相反，同一个键要接在两轮的对角上：车头朝北时，一个键接左前轮北边那格和右前轮南边那格，另一个键接剩下两格。接成同一边，两个轮子会一个往里一个往外，车不转弯。
- 放的时候正下方是完整顶面的方块，它会被抬高一格：车身先架空一格再装悬架（垫的东西放在胶框外面）。
- 前进键接定向齿轮换向器的直输端，倒车键接反转端，和飞艇的动力一样。
- 设置框里有减震强度。

## 装了飞行稳定器（Create: Flight Control）

- 高度稳定器、智能姿态稳定器、线速度耦合器各要接着在转、没过载的轴才干活，还要接了飞控计算机或开了直接施力才真出力。
- 无线红石打字机的四个键经飞控红石代理接到耦合器沿船身 +x、-x、+z、-z 四个方向时，开飞艇就改成"设目标高度 + 给方向"：船不转头，直接朝目标滑，比按键开稳。
- 飞控红石代理哪一面接哪个动作、稳定器的增益与模式，在它们自己的界面里配；现在不会替你配，已经配好的照样能用。没打开的姿态稳定器、耦合器，还有最大速度是 0 的耦合器，开的时候会自己打开、设好。

## 常见的坑

| 现象 | 多半是 | 怎么查、怎么改 |
| --- | --- | --- |
| 拉了杆没变成结构 | 胶没框全、组装器没放在船身的方块上、胶框里有方块没挨着 | 看胶框与组装器的位置；补胶或挪组装器再组装 |
| 组装出来少了一截 | 那一截不在同一块胶里，或两块胶没叠上 | 拆回补胶 |
| 组装时把地面带走了 | 胶框住了地面或脚手架 | 拆回，缩小胶框，把垫的东西挪到框外 |
| 种类是"只是结构" | 没有座位，或没有无线红石打字机这类控制件 | 加座位、控制件 |
| 种类说不清 | 外框太大读不全，或有格没加载 | 走近再看；船太大就拆小 |
| 升力不够 / 气球没充起来 | 燃烧室上面第一块不是蒙皮或羊毛、气球漏气（缺块）、气球太小、船太重、升力键收端没挨着燃烧室 | `machine_inspect` 的 `balance` 看 `lift_ratio`；加大气球、加燃烧室、减重 |
| 一头栽 / 歪着 | 重心偏、推力作用点离重心太远 | `balance=ballast` 看配重放哪；推力装在重心高度附近 |
| 桨不转 | 引擎没燃料、换向器没信号、过载、风帆不够两块 | `machine_inspect` 看转速与应力；试按时看动力键有没有让船挪 |
| 一个键开了两样东西 | 收端同时挨着两个部件，或收端充能的方块把信号传给了旁边的部件 | 把收端挪到只挨着一个部件的地方 |
| 松开键东西还在动 | 别处有同频的发射端一直在发 | 换这辆专用的频率组合 |
